URSUS Loft · Windows 10 / 11

URSUS Link

PC에서 파일과 폴더를 직접 공유합니다.

Microsoft Store에서 구매

원하는 폴더를 선택하고 링크 하나로 파일을 공유하세요. URSUS Link는 Windows PC의 사진, 영상, 작업 자료처럼 용량이 큰 파일도 간편하게 전달하도록 만든 파일 공유 앱입니다. 파일을 먼저 별도의 클라우드 저장소에 업로드할 필요가 없습니다.

사용 방법은 간단합니다. 공유할 폴더를 선택하고 공유를 시작한 다음, 생성된 링크와 4자리 PIN을 받는 사람에게 알려주세요. 받는 사람은 URSUS Link를 구매하거나 별도 앱을 설치하지 않아도 지원되는 웹 브라우저에서 공유 파일을 확인하고 다운로드할 수 있습니다.

파일은 보내는 PC에서 받는 사람의 브라우저로 HTTPS를 통해 직접 전송됩니다. 별도 파일 보관 서버에 원본을 저장하지 않습니다. 대용량 파일 공유에도 사용할 수 있지만 실제 전송 속도와 가능한 파일 크기는 인터넷 연결, 브라우저, 컴퓨터 성능, 저장공간 등에 따라 달라집니다. 공유 중에는 보내는 PC가 켜져 있고 인터넷에 연결되어 있어야 합니다. 한 번 구매하면 구독료 없이 사용할 수 있습니다.

구매 전 연결 호환성 안내
이 앱은 외부에서 보내는 PC로 HTTPS 직접 연결할 수 있는 네트워크가 필요합니다. 공유기 설정, Windows 방화벽, 통신사 정책, 이중 NAT, CGNAT 등의 이유로 외부 연결이 차단될 수 있습니다. 자동 설정으로 해결되지 않고 공유기나 회선 설정도 변경할 수 없다면 인터넷 공유 기능을 사용할 수 없을 수 있습니다. URSUS Link는 중계 서버를 통해 모든 네트워크에서 연결을 보장하지 않습니다. 구매 전에 직접 연결이 가능한 환경인지 확인하세요.

무료 네트워크 호환성 검사

Windows 10/11 x64 · 설치 불필요 · 무료. 파일이나 공유기 설정을 변경하지 않는 읽기 전용 네트워크 추정 검사입니다. 공인 IP 조회 서비스에 요청을 보냅니다. 추정 결과는 연결 성공을 보장하지 않습니다. Windows 10 실기 검사는 아직 하지 않았습니다.
