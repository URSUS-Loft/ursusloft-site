참고 이미지 순서가 중요한 이유

참고 이미지 역할과 순서를 유지해 프롬프트 준비 단계와 외부 업로드 단계를 맞추는 방법입니다.

이 글의 내용

  1. 참고 이미지에는 역할이 필요합니다
  2. 같은 이미지를 같은 순서로 유지합니다
  3. 자주 생기는 실수
  4. 생성 전 확인
  5. Scene Director에서의 순서 확인

참고 이미지에는 역할이 필요합니다

각 이미지는 얼굴, 체형, 의상, 환경, 포즈 또는 렌더링처럼 서로 다른 정보를 전달할 수 있습니다. 참고 이미지 역할을 정하면 어떤 이미지가 어떤 지시를 뒷받침하는지 검토할 수 있습니다.

같은 이미지를 같은 순서로 유지합니다

프롬프트가 참고 이미지 순서를 가리킬 때는, 외부 서비스에도 선택한 이미지를 같은 순서로 업로드합니다. 모든 서비스가 순서를 같은 방식으로 해석한다고 단정하는 것이 아니라, 프롬프트와 업로드 작업을 일치시키는 원칙입니다.

자주 생기는 실수

프롬프트를 만든 뒤 이미지 순서를 바꾸거나, 역할을 확인하지 않고 이미지를 교체하면 작업을 다시 검토하기 어렵습니다. 비어 있는 슬롯과 제외된 이미지는 최종 출력에 포함되지 않는지도 확인합니다.

생성 전 확인

  • 각 이미지 역할을 확인합니다.
  • 프롬프트의 순서를 확인합니다.
  • 같은 이미지를 같은 순서로 업로드합니다.
  • 사용하지 않는 이미지를 제거합니다.

Scene Director에서의 순서 확인

Scene Director는 최대 다섯 개의 참고 이미지 슬롯과 역할을 보여 줍니다. 앱이 이미지를 업로드하지 않으므로 외부 서비스에서는 사용자가 같은 순서를 직접 유지합니다.
