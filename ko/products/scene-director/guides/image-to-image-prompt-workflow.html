가이드

이미지 투 이미지 프롬프트 작성 방법

참고 이미지, 장면 연출과 최종 요청을 구분해 이미지 투 이미지 작업 흐름을 더 명확하게 구성하는 방법입니다.

이 글의 내용

  1. 의도한 결과부터 정하기
  2. 참고 이미지 역할 구분하기
  3. 카메라와 구도 정리하기
  4. 생성 전 검토하기

의도한 결과부터 정합니다

캐릭터 레퍼런스, 장면 표현, 시네마틱 구성처럼 결과의 목적을 먼저 정합니다. 목표가 정해지면 필요한 지시와 보조 지시를 구분하기 쉽습니다.

참고 이미지 역할을 분리합니다

얼굴, 체형, 의상, 환경, 포즈처럼 이미지마다 역할을 정합니다. 정체성과 의상, 환경을 분리하면 서로 다른 출처가 충돌하는지 확인할 수 있습니다.

카메라와 구도를 따로 정리합니다

화면 크기, 렌즈, 높이, 각도와 구도는 캐릭터 설명과 섞지 않고 별도 지시로 둡니다. 카메라 지시는 정체성을 바꾸는 지시가 아니라 표현 방식을 정하는 지시입니다.

생성 전 충돌을 검토합니다

서로 맞지 않는 시점, 신체 설명, 조명과 장면 지시를 확인합니다. 외부 생성 서비스는 같은 프롬프트도 다르게 해석할 수 있으므로 한 번에 한 가지 요소만 바꾸어 결과를 비교합니다.

확인 목록

  • 목표 이미지를 한 문장으로 정리합니다.
  • 각 참고 이미지의 역할을 확인합니다.
  • 서로 모순되는 지시를 지웁니다.
  • 카메라와 구도를 분리합니다.
  • 최종 영문 프롬프트를 검토합니다.

Scene Director의 지원 방식

Scene Director는 참고 이미지 역할과 장면 설정을 정리하고 Final Prompt 또는 Compact Prompt를 만듭니다. 외부 서비스에 프롬프트를 복사하고 이미지를 올리는 작업은 사용자가 직접 진행합니다.
