Windows PC에서 파일을 직접 공유하는 방법을 안내합니다.

PC에서 파일과 폴더를 직접 공유합니다. 링크와 비밀번호는 신뢰하는 사람에게만 비공개로 전달하세요.

공유 시작

공유 폴더의 변경을 눌러 공유할 파일이 들어 있는 폴더를 선택하고 4자리 비밀번호를 확인한 뒤 공유 시작을 누르세요. 링크가 나타나면 링크 복사로 복사해 비밀번호와 함께 받는 사람에게 보내세요. 받는 사람은 브라우저에서 링크를 열고 비밀번호를 입력한 다음 원하는 파일이나 폴더를 다운로드합니다. 끝나면 공유 중지를 누르세요.

링크가 열리지 않을 때

보내는 PC가 켜져 있고 절전 상태가 아니며 공유 중인지 확인하세요. 현재 링크와 비밀번호를 다시 전달하고 받는 사람의 인터넷 연결을 확인하세요. 공유를 다시 시작하거나 네트워크가 바뀌어 링크가 바뀌었다면 새 링크를 보내세요. 링크가 표시되어도 상대방의 접속 성공을 보장하지 않습니다. 계속 열리지 않으면 아래 방화벽과 공유기 안내를 확인하세요.

연결 상태에서 회색은 대기 또는 준비 중, 빨간색은 오류를 뜻합니다. 파란색은 HTTPS 공유가 준비됐지만 외부 접속은 미확인인 상태입니다. 녹색은 실제 외부 인증 요청이 확인된 상태입니다. 링크 생성만으로 외부 접속 성공을 알 수 없습니다.

안전한 연결

앱은 암호화된 HTTPS 연결을 준비합니다. 네트워크나 인증서 서비스에 따라 준비가 실패할 수 있습니다. 브라우저에 보안 경고가 나타나면 링크와 PC의 날짜·시간을 확인하세요. 경고를 무시하거나 보호 기능을 끄지 마세요.

비밀번호와 인증

받는 사람에게 현재 4자리 비밀번호를 알려 주세요. 입력 오류가 나면 숫자와 최신 링크를 확인하세요. 인증이 만료되면 공유가 유지되는지 확인하고 현재 비밀번호로 다시 인증하세요. 비밀번호를 바꾸려면 공유를 중지한 뒤 변경하고 다시 공유를 시작해 현재 링크와 비밀번호를 전달하세요.

다운로드 문제

다운로드가 중단되면 보내는 PC와 공유가 켜져 있는지, 받는 쪽 저장 공간과 인터넷 연결이 충분한지 확인하고 브라우저에서 다시 시도하세요. 폴더를 ZIP으로 받으려면 보내는 PC에도 임시 파일을 위한 여유 공간이 필요합니다. 이어받기는 브라우저와 연결 상태에 따라 달라지며 자동으로 이어진다고 보장할 수 없습니다. 필요한 경우 처음부터 다시 받으세요.

Windows 방화벽

공유를 준비할 때 Windows 관리자 승인 창이 나타날 수 있습니다. 승인하면 앱에 필요한 방화벽 규칙을 준비하려고 합니다. 거부하거나 관리 정책이 차단하면 직접 연결이 제한될 수 있습니다. Windows 보안의 방화벽 및 네트워크 보호에서 활성 네트워크와 허용된 앱을 확인하고, 회사·학교 PC는 관리자에게 문의하세요. 방화벽 전체를 끄지 마세요.

공유기와 네트워크 제한

앱은 가능한 경우 공유기 연결을 자동으로 준비합니다. 공유기가 여러 대이거나 통신사·회사·학교·공용망에서 외부 연결을 막으면 실패할 수 있지만, 이름만으로 사용 불가를 단정할 수는 없습니다. 복구 안내가 나타나면 직접 관리하는 공유기에서만 안내된 설정을 확인하고, 수동 설정과 이번 공유에 대한 승인이 필요한 경우 화면에 따라 진행하세요. 설정이 연결 성공을 보장하지 않습니다. 사용 가능한 IPv6 경로도 환경과 받는 사람의 연결에 따라 달라집니다. 아직 확인되지 않았다면 다른 네트워크에서 시험하거나 관리자에게 확인하세요. 지원되는 모든 직접 연결 경로가 차단되어 변경할 수 없는 환경이라면 이 제품으로 해결할 수 없으므로 구매나 사용을 권장하지 않습니다.

수동 IPv4 복구 화면이 표시되면 직접 관리하는 공유기에서 화면에 표시된 파일 포트를 전달하세요. 인증서용 TCP 80 규칙이 요구되는 경우에만 해당 규칙도 설정하세요. 필요한 수동 설정을 완료한 뒤 확인하세요. 외부 연결은 별도로 확인해야 합니다.

공유 유지와 설정

공유 중에는 보내는 PC와 인터넷 연결을 유지하세요. 창을 닫을 때 트레이에서 계속 실행하도록 선택할 수 있습니다. 트레이에서 창을 열거나 링크를 복사하고 공유를 중지하거나 앱을 종료할 수 있습니다. 공유 중지 또는 종료로 안전하게 공유를 끝내세요. 언어와 화면 모드는 앱 화면에서 변경할 수 있습니다.

Microsoft Store

Microsoft Store 버전에서 새 공유를 시작하려면 유효한 라이선스 확인이 필요할 수 있습니다. 확인 중이거나 실패하면 앱을 구매한 계정으로 Store에 로그인했는지 확인하고 잠시 후 공유 시작을 다시 누르세요. 체험이나 환불 조건은 구매 시 표시된 Microsoft Store 정책을 확인하세요.

추가 도움이 필요할 때

공유 상태, 오류 발생 시점과 Windows·앱 버전을 확인하세요. 로그 복사로 진단 기록을 준비할 수 있습니다. 기록에 PC나 네트워크 정보가 있을 수 있으므로 전달 전 비밀번호, PIN, 공유 링크, 토큰과 개인키를 제거하세요.
