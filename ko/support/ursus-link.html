URSUS Link

지원

Windows PC에서 파일을 직접 공유하는 방법을 안내합니다.

시작하기

URSUS Link는 PC에서 선택한 폴더의 파일을 받는 사람의 브라우저로 직접 공유합니다. 파일은 URSUS Loft 클라우드 저장소에 업로드되지 않습니다.

  1. Shared Folder를 선택합니다.
  2. 4자리 Password를 확인하거나 변경합니다.
  3. Start Sharing을 선택합니다.
  4. Share Link가 생성될 때까지 기다립니다.
  5. Share Link와 비밀번호를 받는 사람에게 전달합니다.
  6. 받는 사람은 링크를 열고 PIN/비밀번호를 입력한 뒤 파일을 다운로드합니다.
  7. 완료되면 Stop Sharing을 선택합니다.

공유 링크와 브라우저 다운로드

받는 사람은 URSUS Link를 설치할 필요가 없으며 최신 웹 브라우저만 있으면 됩니다. Share Link와 비밀번호는 비공개로 전달하고 공유 중에는 보내는 사람의 PC를 온라인 상태로 유지하세요.

HTTPS와 HTTP fallback

URSUS Link는 기본적으로 HTTPS를 준비하며 해당하는 경우 최대 세 번 시도합니다. 그래도 HTTPS를 준비할 수 없으면 사용자가 명시적으로 HTTP fallback을 선택할 수 있습니다. 이 공유 세션은 전송 중 암호화되지 않습니다.

대용량 파일과 백그라운드 공유

대용량 파일은 디스크에서 스트리밍되며 Range/이어받기 요청을 지원합니다. 폴더 다운로드에는 임시 로컬 ZIP64 패키지가 사용될 수 있습니다. 공유 중에는 시스템 트레이에서 계속 실행할 수 있으며 전송이 끝날 때까지 앱과 PC를 켜 두세요.

연결 문제 해결

링크가 열리지 않으면 공유가 활성 상태인지 확인하고 현재 링크를 다시 복사한 뒤 보내는 사람의 PC를 온라인 상태로 유지하세요. 요청 시 Windows Firewall 접근을 허용해야 합니다. 일부 라우터, CGNAT, 회사·공용·모바일 네트워크는 직접 연결을 차단할 수 있습니다.
