Scene Director

지원

Windows에서 사용하는 현재 Scene Director 작업 흐름을 위한 안내입니다.

시작하기

Scene Director는 외부 AI 이미지 생성 도구를 위한 로컬 프롬프트 작성 및 장면 연출 도구입니다. 참고 이미지 역할, 장면 지시와 영어 Final Prompt 또는 Compact Prompt 출력을 정리합니다.

  1. Project Type을 선택합니다.
  2. 최대 다섯 개의 Reference Images를 추가하고 사용할 각 이미지에 명확한 역할을 지정합니다.
  3. Character, Camera, Pose, Face, Costume, Environment, Rendering 및 Additional Instructions를 설정합니다.
  4. Final Prompt 또는 Compact Prompt를 검토합니다.
  5. 외부 AI 이미지 생성 도구에 프롬프트를 복사하고 같은 Reference Images를 같은 순서로 첨부합니다.

참고 이미지와 역할

Reference Images는 Scene Director에서 업로드되거나 분석되지 않습니다. 로컬 미리보기와 프롬프트 정리를 위해 사용자의 로컬 장치에서 선택됩니다.

외부 AI 도구에도 Scene Director에 표시된 정확한 순서대로 같은 참고 이미지를 첨부하세요. 순서가 바뀌면 외부 도구가 잘못된 출처를 따를 수 있습니다. 비어 있는 슬롯과 역할이 Role Required로 남아 있는 이미지는 Final Prompt와 Compact Prompt에서 제외됩니다.

프롬프트 설정

사이드바에서는 Project Type, Character, Multi-Character, Camera, Pose, Face, Costume, Environment, Rendering 및 Additional Instructions를 설정할 수 있습니다. Help 대화상자에는 Reference Images, Final Prompt (English), Composition Preview도 포함됩니다.

Final Prompt는 현재 설정에서 생성되는 자세한 영어 프롬프트입니다. 의도적으로 영어 전용이며 Compact Prompt보다 상세합니다. Scene Director가 최종 이미지를 직접 생성하지는 않습니다.

세션과 프리셋

Scene Director는 현재 세션을 자동 저장하고 앱을 열 때 복원합니다. 상태 표시줄에는 Auto saved와 Last saved: just now가 표시됩니다.

Save Preset으로 현재 상태를 이름으로 저장합니다. Load Preset은 저장된 프리셋을 복원하고 Delete Preset은 프리셋을 제거합니다. 기존 이름으로 저장하면 해당 프리셋이 업데이트됩니다.

New Prompt를 사용하면 현재 프롬프트 작업 공간을 기본값으로 초기화합니다. 저장된 프리셋은 삭제되지 않습니다.

마지막 세션 데이터는 %APPDATA%\Scene Director\last_session.json에 저장됩니다. 프리셋은 %APPDATA%\Scene Director\presets.json에 저장됩니다.

플랫폼과 외부 서비스

Scene Director는 현재 Windows용입니다. 이미지 생성 서비스가 아니며 참고 이미지를 다른 서비스에 대신 업로드하지 않습니다. 외부 AI 이미지 생성 서비스는 사용자가 선택하고 참고 이미지도 사용자가 직접 업로드합니다.
