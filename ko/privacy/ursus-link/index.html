URSUS Link

개인정보 처리방침

시행일: 2026년 8월 24일

English | 한국어

1. 개요

URSUS Link는 URSUS Loft가 운영합니다. 보내는 사람의 PC에서 받는 사람의 웹 브라우저로 파일을 직접 공유할 수 있게 하는 애플리케이션입니다.

2. URSUS Link가 처리하는 정보

공유 기능을 제공하기 위해 앱은 보내는 사람이 선택한 폴더, 해당 폴더 안의 파일 이름·경로·메타데이터·내용, 공유 링크 토큰, PIN과 받는 사람 세션 데이터, 로컬 네트워크 및 연결 정보, 받는 사람의 요청 및 전송 정보를 처리합니다. 링크 복사를 선택하면 생성된 링크를 Windows 클립보드에 씁니다. 클립보드의 기존 내용은 읽지 않습니다.

URSUS Link에는 사용자 계정 시스템이 없고 결제 카드 정보를 직접 처리하지 않습니다. 광고 분석, 행동 추적 또는 제3자 광고 SDK도 포함하지 않습니다.

3. 공유하는 파일

URSUS Link는 보내는 사람이 공유용으로 선택한 파일과 폴더에 접근합니다. 공유 파일은 보내는 사람의 PC에서 받는 사람의 브라우저로 직접 전송됩니다. URSUS Link는 공유 파일을 URSUS Loft의 클라우드 저장소나 릴레이 서비스에 업로드하지 않습니다.

폴더 또는 여러 항목을 다운로드할 때 앱은 보내는 사람 PC에 로컬 ZIP64 패키지를 만들 수 있습니다. 이 패키지에는 선택한 공유 내용이 포함되며 받는 사람에게 직접 제공됩니다.

4. 네트워크 및 연결 정보

직접 공유를 준비하고 진단하기 위해 앱은 로컬 IP 주소, 기본 게이트웨이, Windows 네트워크 또는 방화벽 상태, 공인 IP 주소 및 공유 포트를 처리할 수 있습니다. 다운로드 제공에 필요한 PIN 시도 제한과 활성 전송 처리를 위해 받는 사람의 IP 주소, 요청·범위·세션·요청 파일 정보를 처리할 수 있습니다.

받는 사람의 IP 주소, PIN, 공유 링크 토큰 및 세션 쿠키 값은 앱의 진단 로그에 보관하지 않습니다.

5. 로컬 데이터 저장

URSUS Link는 설정, 순환 진단 로그, 로컬에서 생성한 TLS 및 ACME 키와 인증서, ZIP/패키지 캐시 파일을 %LOCALAPPDATA%\URSUS Link 아래에 저장할 수 있습니다. 설정에는 마지막으로 선택한 공유 폴더 경로, 언어 및 공유 중 창 닫기 기본 설정이 포함됩니다.

진단 로그는 로컬 장치에 저장되며 URSUS Loft에 자동 업로드되지 않습니다. 앱은 전체 Windows 경로, 원본 클라이언트 IP 주소, PIN, 토큰, 세션 쿠키 및 비밀값 형태의 값을 로그에서 가립니다.

6. 제3자 서비스

공인 IP 주소를 확인하기 위해 앱은 api.ipify.org, icanhazip.com 또는 ifconfig.me를 사용할 수 있습니다. 이 서비스들은 요청 연결 IP와 앱 user-agent를 받고 공인 IPv4 주소를 반환합니다. 이 조회를 위해 공유 파일 내용, PIN 또는 공유 링크 토큰을 보내지 않습니다.

HTTPS 인증서 발급 또는 갱신을 위해 앱은 Let's Encrypt를 사용할 수 있습니다. 발급에 필요한 인증서 요청과 검증 정보가 전송되지만 TLS 개인 키와 ACME 계정 개인 키는 보내는 사람의 PC에 남아 있습니다. 앱은 직접 외부 연결을 준비하기 위해 보내는 사람의 로컬 네트워크 라우터와 통신할 수도 있습니다.

7. 연결 보안

URSUS Link는 기본적으로 HTTPS 링크 준비를 시도합니다. 해당하는 HTTPS 준비 실패의 경우 최대 세 번 재시도합니다. HTTPS를 준비할 수 없으면 보내는 사람은 HTTP로 계속 사용, HTTPS 재시도 또는 취소를 명시적으로 선택할 수 있습니다. HTTP는 자동으로 선택되지 않습니다.

HTTP로 공유하는 경우 해당 공유 세션에서 전송되는 데이터는 전송 구간에서 암호화되지 않습니다.

8. 데이터 보관

활성 공유 세션과 전송 데이터는 메모리에 보관됩니다. 받는 사람 인증 세션은 8시간 후 만료되고 공유를 중지하면 활성 세션 상태가 정리됩니다. 완성된 패키지 파일은 24시간 후 정리 대상이 되며 캐시 크기 제한에 따른 정리도 적용됩니다. 로그는 고정 일수 보관 대신 크기 기준 순환 방식을 사용합니다.

앱을 제거한 뒤에도 일부 로컬 설정, 로그, TLS 자료 및 캐시 데이터가 남을 수 있습니다. 로컬 앱 데이터를 제거하려면 앱 제거 후 %LOCALAPPDATA%\URSUS Link를 직접 삭제할 수 있습니다.

9. 데이터 공유

공유 파일, 파일명, 목록 및 폴더/패키지 내용은 공유 링크를 사용하고 필요한 PIN 절차를 완료한 받는 사람에게 직접 제공됩니다. 위에 설명한 공인 IP 조회 및 인증서 서비스는 각 서비스를 제공하는 데 필요한 정보만 받습니다. URSUS Loft는 URSUS Link 파일 전송을 위한 클라우드 릴레이나 저장 서비스를 운영하지 않습니다.

10. 사용자의 선택

공유 폴더 선택, PIN 변경 또는 재생성, 공유 중지, 앱 제거 후 로컬 앱 데이터 삭제를 할 수 있습니다. 공유를 중지하면 로컬 공유 서버가 중지되고 활성 공유 링크를 사용할 수 없게 됩니다.

11. 아동 개인정보

URSUS Link는 파일 공유 도구이며 아동 계정 또는 프로필 기능을 포함하지 않습니다.

12. 이 방침의 변경

URSUS Loft는 앱의 정보 처리 방식이 바뀌면 이 방침을 업데이트할 수 있습니다. 개정된 방침을 게시할 때 시행일을 업데이트합니다.
