指南

如何构建更清晰的 Image-to-Image 提示词

在使用外部图像生成服务前，将参考图像、创意指导和最终说明分离整理的一套实用工作流程。

本页内容

  1. 从预期结果开始
  2. 分离参考图像角色
  3. 定义相机与构图
  4. 生成前检查

Image-to-Image 提示词的作用

Image-to-Image 提示词将文字指导与一张或多张参考图像结合。文字部分说明要保留什么、改变什么，以及你想创建哪种图像。有效的提示词并不只是更长，而是让各项说明之间的关系更容易理解。

从预期结果开始

先确定目标是角色参考图、场景重现还是电影感构图。这个决定有助于区分哪些细节是必要的，哪些应保持次要。收集更多描述词之前，先写清楚你需要的结果。

分离参考图像角色

让每张参考图像承担明确任务。一张图可用于身份，另一张可支持服装，其他图可描述环境或姿势。将身份与服装和环境分开，更容易发现不同来源之间的矛盾。

定义相机与构图

将景别、镜头、相机高度、角度、取景和构图作为独立指导描述。相机选择会影响主体呈现，因此不应埋在身份或服装说明中。

避免冲突说明

检查是否存在不兼容的视角、身体描述、光照或场景。明确优先级后，删除或改写与预期结果竞争的细节。外部图像生成服务仍可能对相同提示词作出不同解释，因此应一次只更改一个受控细节来比较结果。

实用检查清单

  • 说明预期图像。
  • 为每张参考图像分配角色。
  • 将身份、服装和环境分开。
  • 单独指定相机与构图。
  • 检查优先级并移除冲突。

Scene Director 如何支持此工作流程

Scene Director 在一个 Windows 工作区中整理参考图像角色、场景控制以及 Final Prompt 或 Compact Prompt 输出。它准备英文提示词文本；你在外部服务中使用这些文本并上传所选参考图像。
