URSUS Link

从电脑直接共享文件和文件夹。

在 Microsoft Store 获取

选择想要共享的文件夹，通过一个链接轻松分享文件。URSUS Link 让你从 Windows 电脑直接发送照片、视频、工作资料和大文件，无需先上传到其他云存储服务。

操作很简单：选择文件夹、开始共享，然后把生成的链接和必需的四位 PIN 码发给接收者。对方无需购买或安装 URSUS Link，只需使用受支持的浏览器，即可查看和下载共享文件。

文件通过 HTTPS 从发送方电脑直接传输到接收者浏览器，原始文件不会预先存放在独立的文件托管服务器上。适合分享大文件，但实际速度和可处理的文件大小取决于网络、浏览器、电脑性能和存储空间。共享期间，发送方电脑必须保持开机并联网。一次购买，无需订阅。

购买前请注意网络兼容性
此应用要求外部网络能够通过 HTTPS 直接连接发送方电脑。路由器、防火墙、运营商限制、双重 NAT 或 CGNAT 可能导致外部连接失败。如果自动配置无法解决问题，且无法更改路由器或网络设置，则可能无法通过互联网共享。URSUS Link 不会通过文件中继服务器保证在所有网络中均可连接。购买前请确认网络支持直接连接。
