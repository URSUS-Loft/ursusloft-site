URSUS Link

隐私政策

生效日期：2026年8月24日

1. 概述

URSUS Link 由 URSUS Loft 运营。它让发送者可以将文件从自己的电脑直接共享到接收者的网页浏览器。

2. URSUS Link 处理的信息

为提供共享功能，应用会处理发送者选择的文件夹、其中的文件名、路径、元数据和内容、Share Link 令牌、PIN 和接收者会话数据、本地网络与连接信息，以及接收者的请求和传输信息。选择 Copy Link 时，应用会把生成的链接写入 Windows 剪贴板，但不会读取剪贴板内容。

URSUS Link 没有用户账户系统，也不直接处理支付卡信息。它不包含广告分析、行为跟踪或第三方广告 SDK。

3. 您共享的文件

应用访问发送者选择用于共享的文件和文件夹。文件从发送者电脑直接发送到接收者浏览器，不会上传到 URSUS Loft 云存储或中继服务。

下载文件夹或多个项目时，应用可能在发送者电脑上创建本地 ZIP64 包。该包包含所选共享内容，并直接提供给接收者。

4. 网络与连接信息

为准备和诊断直接共享，应用可能处理本地 IP 地址、默认网关、Windows 网络或防火墙状态、公网 IP 地址及共享端口。为临时限制 PIN 尝试和处理活动传输，可能处理接收者 IP 地址以及提供下载所需的请求、Range、会话和目标文件信息。

接收者 IP 地址、PIN、Share Link 令牌和会话 Cookie 值不会保留在诊断日志中。

5. 本地数据存储

应用可能在 %LOCALAPPDATA%\URSUS Link 中存储设置、轮转诊断日志、本地生成的 TLS/ACME 密钥和证书，以及 ZIP/包缓存。设置包括上次选择的共享文件夹路径、语言和共享期间关闭窗口的偏好。

诊断日志保存在本地，不会自动上传到 URSUS Loft。格式化日志会隐藏完整 Windows 路径、原始客户端 IP、PIN、令牌、会话 Cookie 和类似机密的值。

6. 第三方服务

应用可能使用 api.ipify.org、icanhazip.com 或 ifconfig.me 查询公网 IP。这些服务会收到请求连接 IP 和应用 User-Agent，并返回公网 IPv4。共享文件内容、PIN 和 Share Link 令牌不会为此查询而发送。

应用可能使用 Let's Encrypt 颁发或更新 HTTPS 证书。必要的证书请求与验证信息会被发送；TLS 私钥和 ACME 账户私钥保留在发送者电脑上。应用也可能与发送者局域网路由器通信，以准备直接外部连接。

7. 连接安全

URSUS Link 通常会尝试准备 HTTPS 链接。对于符合条件的 HTTPS 设置失败，最多重试三次。如果无法准备 HTTPS，发送者可以明确选择继续使用 HTTP、重试 HTTPS 或取消。应用绝不会自动选择 HTTP。

使用 HTTP 时，该共享会话中传输的数据不会在传输过程中加密。

8. 数据保留

活动共享会话和传输数据保留在内存中。接收者认证会话八小时后过期，停止共享时活动会话状态会被清除。已完成的包文件可在24小时后及缓存大小清理时删除。日志按大小轮转，而不是按固定天数保留。

卸载后，部分本地设置、日志、TLS 材料和缓存数据可能仍然存在。若要删除，可在卸载后手动删除 %LOCALAPPDATA%\URSUS Link。

9. 数据共享

共享文件、文件名、列表以及文件夹/包内容会直接提供给使用 Share Link 并完成所需 PIN 步骤的接收者。上述公网 IP 查询和证书服务只会收到提供相应功能所需的信息。URSUS Loft 不运营用于 URSUS Link 文件传输的云中继或存储服务。

10. 您的选择

您可以选择共享文件夹、更改或重新生成 PIN、停止共享，并在卸载后删除本地应用数据。停止共享会关闭本地共享服务器，使当前 Share Link 失效。

11. 儿童隐私

URSUS Link 是文件共享工具，不包含儿童账户或个人资料。

12. 政策变更

当应用的数据处理方式发生变化时，URSUS Loft 可能更新本政策。修订政策发布时会更新生效日期。
