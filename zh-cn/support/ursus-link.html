帮助您直接从 Windows 电脑共享文件。

从电脑直接共享文件和文件夹。 仅私下向信任的人发送链接和密码。

开始共享

选择共享文件夹旁的“更改”，选择包含文件的文件夹，确认四位密码后开始共享。链接出现后复制链接并连同密码发给接收方。对方在浏览器中打开链接、输入密码，然后下载所需文件或文件夹。完成后停止共享。

链接无法打开

检查发送电脑已开机、联网、未睡眠且仍在共享。再次发送当前链接和密码，并检查接收方网络。重启共享或网络变化后链接改变时，请发送新链接。显示链接不代表对方已成功连接。如果仍失败，请检查下方防火墙和路由器说明。

连接状态中，灰色表示等待或准备，红色表示错误。蓝色表示 HTTPS 共享已准备好，但外部访问尚未确认；绿色表示已观察到通过认证的外部请求。仅生成链接不能证明外部可访问。

安全连接

应用会准备加密的 HTTPS 连接。网络或证书服务可能导致准备失败。浏览器出现安全警告时，请检查链接和电脑日期时间；不要忽略警告或关闭保护。

密码和认证

向接收方提供当前四位密码。失败时检查数字和最新链接。浏览器认证过期时，确认共享仍在运行并用当前密码重新认证。更改密码前先停止共享，更改后重新开始并发送当前链接和密码。

下载问题

下载中断时，检查发送电脑和共享是否运行、接收方存储空间和网络是否足够，然后在浏览器重试。文件夹 ZIP 还需要发送电脑有临时文件空间。能否续传取决于浏览器和网络，不能保证；必要时从头下载。

Windows 防火墙

准备共享时 Windows 可能请求管理员批准。批准后应用会尝试准备所需防火墙规则。拒绝或管理策略可能限制直接连接。在 Windows 安全中心检查活动网络和允许的应用；工作或学校电脑请咨询管理员。不要关闭整个防火墙。

路由器和网络限制

条件允许时应用会自动准备路由器连接。多个路由器或运营商、工作、学校、公共网络阻止入站连接可能导致失败，但不能仅凭网络名称判定不可用。出现恢复提示时，只检查自己管理的路由器；需要手动设置和本次共享授权时按照屏幕提示操作。设置不保证连接成功。IPv6 也取决于双方网络。尚未确认时可尝试其他网络或询问管理员。如果所有支持的直接连接路径均被阻止且无法更改，本产品无法解决该环境，不建议购买或使用。

出现 IPv4 手动恢复画面时，在自己管理的路由器转发画面所示文件端口。仅在画面要求时设置证书 TCP 80 规则。完成必要设置后确认。仍需另行检查外部访问。

保持共享和设置

共享时保持发送电脑和网络开启。关闭窗口时可选择在系统托盘继续运行；托盘可打开窗口、复制链接、停止共享或退出。停止共享或退出可安全结束访问。语言和外观可在应用界面更改。

Microsoft Store

Microsoft Store 版本开始新共享前可能需要验证有效许可证。验证中或失败时，确认 Store 使用获取应用的账户登录，稍后再次开始共享。试用或退款条件请查看购买时显示的 Microsoft Store 条款。

需要更多帮助

请记录共享状态、出错时间以及 Windows 和应用版本。可复制日志以准备诊断记录。记录可能包含电脑或网络信息；分享前请删除密码、PIN、共享链接、令牌和私钥。
