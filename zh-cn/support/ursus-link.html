URSUS Link

支持

帮助您直接从 Windows 电脑共享文件。

开始使用

URSUS Link 将电脑中所选文件夹的文件直接共享到接收方的浏览器。文件不会上传到 URSUS Loft 云存储。

  1. 选择 Shared Folder。
  2. 确认或更改四位 Password。
  3. 选择 Start Sharing。
  4. 等待 Share Link 创建完成。
  5. 将 Share Link 和密码发送给接收方。
  6. 接收方打开链接，输入 PIN/密码并下载文件。
  7. 完成后选择 Stop Sharing。

共享链接与浏览器下载

接收方无需安装 URSUS Link，只需使用现代网页浏览器。请私下发送 Share Link 和密码，并在共享期间保持发送方电脑在线。

HTTPS 与 HTTP 回退

URSUS Link 通常会准备 HTTPS，并在符合条件的设置失败时最多重试三次。如果仍无法准备 HTTPS，用户可以明确选择 HTTP 回退；该共享会话的传输不会加密。

大文件与后台共享

大文件从磁盘流式传输，并支持 Range/续传请求。文件夹下载可能使用本地临时 ZIP64 包。共享时 URSUS Link 可在系统托盘中继续运行；请保持应用和电脑运行，直至传输完成。

连接故障排除

如果链接无法打开，请确认共享仍在进行，重新复制当前链接，并保持发送方电脑在线。系统提示时请允许 Windows Firewall 访问。某些路由器、CGNAT、企业、公共或移动网络可能会阻止直接入站连接。

联系支持

如需 URSUS Link 支持，请联系 support@ursusloft.com。
