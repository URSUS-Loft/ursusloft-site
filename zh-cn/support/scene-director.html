Scene Director

支持

关于当前 Scene Director Windows 工作流程的指导。

开始使用

Scene Director 是面向外部 AI 图像生成工具的本地提示词起草与场景指导实用程序。它整理参考图像角色、场景指导以及英文 Final Prompt 或 Compact Prompt 输出。

  1. 选择 Project Type。
  2. 添加最多五张 Reference Images，并为每张要使用的图像分配明确角色。
  3. 设置 Character、Camera、Pose、Face、Costume、Environment、Rendering 和 Additional Instructions。
  4. 检查 Final Prompt 或 Compact Prompt。
  5. 将提示词复制到外部 AI 图像生成工具，并按相同顺序附加相同参考图像。

Reference Images 与角色

Reference Images 不会被 Scene Director 上传或分析。它们从用户本地设备中选择，仅用于本地预览和提示词整理。

请按照 Scene Director 中显示的准确顺序，将相同参考图像附加到外部 AI 工具。改变顺序可能导致外部工具采用错误来源。空槽位以及角色仍为 需要指定角色 的图像不会包含在 Final Prompt 和 Compact Prompt 中。

提示词控制

侧边栏提供 Project Type、Character、Multi-Character、Camera、Pose、Face、Costume、Environment、Rendering 和 Additional Instructions 控制。Help 对话框还包含 Reference Images、Final Prompt（英文）和 Composition Preview。

Final Prompt 是根据当前设置生成的详细英文提示词。它按设计仅使用英文，并比 Compact Prompt 更详细。Scene Director 不会直接生成最终图像。

会话与预设

Scene Director 会自动保存当前会话，并在应用打开时恢复。状态栏显示 Auto saved 和 Last saved: just now。

使用 Save Preset 按名称保存当前状态。Load Preset 恢复已保存预设，Delete Preset 删除预设。使用现有名称保存会更新该预设。

使用 New Prompt 将当前提示词工作区重置为默认状态。已保存预设不会被删除。

上次会话数据存储在 %APPDATA%\Scene Director\last_session.json。预设存储在 %APPDATA%\Scene Director\presets.json。

平台与外部服务

Scene Director 当前适用于 Windows。它不是图像生成服务，也不会替你将参考图像上传到其他服务。你需要自行选择外部 AI 图像生成服务，并在那里上传参考图像。
