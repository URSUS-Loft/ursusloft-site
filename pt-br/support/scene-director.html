Scene Director

Suporte

Orientações para o fluxo de trabalho atual do Scene Director no Windows.

Primeiros passos

O Scene Director é um utilitário local de elaboração de prompts e direção de cena para ferramentas externas de geração de imagens por IA. Ele organiza funções de imagens de referência, orientações de cena e a saída de Final Prompt ou Compact Prompt em inglês.

  1. Selecione um Project Type.
  2. Adicione até cinco Reference Images e atribua uma função clara a cada imagem que deseja usar.
  3. Defina Character, Camera, Pose, Face, Costume, Environment, Rendering e Additional Instructions.
  4. Revise o Final Prompt ou o Compact Prompt.
  5. Copie o prompt para uma ferramenta externa de geração de imagens por IA e anexe as mesmas imagens de referência na mesma ordem.

Reference Images e funções

As Reference Images não são enviadas nem analisadas pelo Scene Director. Elas são selecionadas no dispositivo local para prévia local e organização do prompt.

Anexe as mesmas imagens de referência à ferramenta externa de IA na ordem exata mostrada no Scene Director. Alterar a ordem pode fazer a ferramenta externa seguir a fonte errada. Espaços vazios e imagens cuja função continue como Função obrigatória são excluídos de Final Prompt e Compact Prompt.

Controles do prompt

A barra lateral oferece controles de Project Type, Character, Multi-Character, Camera, Pose, Face, Costume, Environment, Rendering e Additional Instructions. A janela de ajuda também inclui Reference Images, Final Prompt (em inglês) e Composition Preview.

Final Prompt é o prompt detalhado em inglês gerado a partir das configurações atuais. Ele permanece somente em inglês por design e é mais detalhado que Compact Prompt. O Scene Director não gera diretamente a imagem final.

Sessões e predefinições

O Scene Director salva automaticamente a sessão atual e a restaura quando o aplicativo é aberto. A barra de status mostra Auto saved e Last saved: just now.

Use Save Preset para salvar o estado atual com um nome. Load Preset restaura uma predefinição salva e Delete Preset a remove. Salvar com um nome existente atualiza essa predefinição.

Use New Prompt para redefinir a área de trabalho atual do prompt para os padrões. As predefinições salvas não são excluídas.

Os dados da última sessão são armazenados em %APPDATA%\Scene Director\last_session.json. As predefinições são armazenadas em %APPDATA%\Scene Director\presets.json.

Plataforma e serviços externos

O Scene Director está disponível atualmente para Windows. Ele não é um serviço de geração de imagens e não envia imagens de referência para outro serviço por você. Você escolhe o serviço externo de geração de imagens por IA e envia as imagens de referência por conta própria.
