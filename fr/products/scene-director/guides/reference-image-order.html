Guide pratique

Pourquoi l’ordre des images de référence est important

Gardez les rôles attribués et la séquence des images visibles lorsque vous passez de la préparation du prompt à un flux externe de génération.

Sur cette page

  1. Définir les rôles
  2. Conserver la même séquence
  3. Vérifier avant la génération

Les images de référence ont besoin de rôles définis

Les images de référence peuvent transmettre le visage, le corps, le costume, l’environnement, la pose ou la direction de rendu. Attribuer un rôle permet d’indiquer clairement quelle image soutient chaque instruction.

Conserver les mêmes images dans la même séquence

Lorsqu’un prompt fait référence à l’ordre des images, téléversez les mêmes images sélectionnées dans cet ordre vers le service externe. Il s’agit d’un principe de flux de travail, et non d’une affirmation selon laquelle tous les services interprètent les images exactement de la même manière.

Emplacements vides et images exclues

N’inventez pas de rôle pour un emplacement vide. Dans Scene Director, les emplacements vides et les images marquées Role Required sont exclus de la sortie du prompt. Vérifiez ce qui est inclus avant de copier un prompt.

Erreurs d’ordre fréquentes

Modifier l’ordre après avoir rédigé le prompt, remplacer une image sans vérifier son rôle ou utiliser des sources d’identité contradictoires rendent le flux de travail plus difficile à contrôler.

Liste de contrôle avant génération

  • Vérifiez que chaque image sélectionnée a un objectif.
  • Vérifiez l’ordre des références dans le prompt.
  • Téléversez les mêmes images dans la même séquence.
  • Retirez les sources inutilisées ou exclues.

Comment Scene Director rend l’ordre visible

Scene Director affiche jusqu’à cinq emplacements de référence et leurs rôles attribués pendant la création d’un Final Prompt ou d’un Compact Prompt. L’application ne téléverse pas les images ; vous les joignez dans le flux de travail externe.
