Cómo crear prompts Image-to-Image más claros

Un flujo de trabajo práctico para separar referencias, dirección creativa e instrucciones finales antes de utilizar un servicio externo de generación de imágenes.

En esta página

  1. Empieza por el resultado deseado
  2. Separa las funciones de las referencias
  3. Define la cámara y la composición
  4. Revisa antes de generar

Qué hace un prompt Image-to-Image

Un prompt Image-to-Image combina instrucciones escritas con una o varias referencias. La parte escrita explica qué debe conservarse, qué debe cambiar y qué tipo de imagen intentas crear. Un prompt útil no es simplemente más largo: hace que la relación entre las instrucciones resulte más fácil de entender.

Empieza por el resultado deseado

Decide si el objetivo es una referencia de personaje, una recreación de escena o una composición cinematográfica. Esa decisión ayuda a determinar qué detalles son esenciales y cuáles deben quedar en segundo plano. Escribe el resultado que necesitas antes de acumular frases descriptivas adicionales.

Separa las funciones de las referencias

Asigna una tarea a cada referencia. Una imagen puede establecer la identidad, otra puede servir para el vestuario y otra puede describir el entorno o la pose. Mantener la identidad separada del vestuario y del entorno facilita detectar cuándo dos fuentes se contradicen.

Define la cámara y la composición

Describe el tamaño del plano, el objetivo, la altura de cámara, el ángulo, el encuadre y la composición como una indicación independiente. Las decisiones de cámara afectan a la apariencia del sujeto, por lo que no deben quedar ocultas dentro de las notas de identidad o vestuario.

Evita instrucciones contradictorias

Comprueba si hay puntos de vista, descripciones corporales, iluminaciones o escenas incompatibles. Cuando las prioridades estén claras, elimina o reescribe los detalles que compitan con el resultado deseado. Un servicio externo de generación de imágenes puede interpretar de forma distinta el mismo prompt, así que compara los resultados cambiando un único detalle controlado cada vez.

Lista de comprobación práctica

  • Indica la imagen deseada.
  • Asigna una función a cada referencia.
  • Mantén separadas la identidad, el vestuario y el entorno.
  • Especifica por separado la cámara y la composición.
  • Revisa las prioridades y elimina los conflictos.

Cómo ayuda Scene Director en este flujo de trabajo

Scene Director organiza las funciones de las referencias, los controles de escena y la salida de Final Prompt o Compact Prompt en un único espacio de trabajo para Windows. Prepara el texto del prompt en inglés; tú utilizas ese texto y cargas las referencias elegidas en un servicio externo.
