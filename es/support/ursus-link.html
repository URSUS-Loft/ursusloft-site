URSUS Link

Soporte

Ayuda para compartir archivos directamente desde un PC con Windows.

Primeros pasos

URSUS Link comparte los archivos de una carpeta de tu PC directamente con el navegador del destinatario. Los archivos no se suben al almacenamiento en la nube de URSUS Loft.

  1. Elige Shared Folder.
  2. Comprueba o cambia la Password de cuatro dígitos.
  3. Selecciona Start Sharing.
  4. Espera a que se cree el Share Link.
  5. Envía el Share Link y la contraseña al destinatario.
  6. El destinatario abre el enlace, introduce el PIN o la contraseña y descarga los archivos.
  7. Selecciona Stop Sharing cuando termines.

Enlace compartido y descargas en el navegador

El destinatario no necesita instalar URSUS Link; basta con un navegador web actual. Envía el Share Link y la contraseña de forma privada y mantén conectado el PC remitente mientras compartes.

HTTPS y alternativa HTTP

URSUS Link prepara normalmente HTTPS y reintenta hasta tres veces los fallos de configuración aplicables. Si HTTPS sigue sin estar disponible, puedes elegir explícitamente la alternativa HTTP. Esa sesión no estará cifrada durante la transferencia.

Archivos grandes y uso en segundo plano

Los archivos grandes se transmiten desde el disco y admiten solicitudes Range y reanudación. Las descargas de carpetas pueden usar un paquete ZIP64 local temporal. URSUS Link puede seguir disponible desde la bandeja del sistema; mantén la aplicación y el PC encendidos hasta terminar.

Solución de problemas de conexión

Si el enlace no abre, confirma que la sesión sigue activa, vuelve a copiar el enlace actual y mantén conectado el PC remitente. Permite el acceso de Windows Firewall cuando se solicite. Algunos routers, CGNAT y redes corporativas, públicas o móviles pueden bloquear conexiones directas entrantes.
