Scene Director

Soporte

Orientación para el flujo de trabajo actual de Scene Director en Windows.

Primeros pasos

Scene Director es una utilidad local para redactar prompts y dirigir escenas destinada a herramientas externas de generación de imágenes mediante IA. Organiza funciones de imágenes de referencia, indicaciones de escena y la salida de Final Prompt o Compact Prompt en inglés.

  1. Selecciona un Project Type.
  2. Añade hasta cinco Reference Images y asigna una función clara a cada imagen que quieras utilizar.
  3. Configura Character, Camera, Pose, Face, Costume, Environment, Rendering y Additional Instructions.
  4. Revisa el Final Prompt o el Compact Prompt.
  5. Copia el prompt en una herramienta externa de generación de imágenes mediante IA y adjunta las mismas imágenes de referencia en el mismo orden.

Reference Images y funciones

Scene Director no carga ni analiza las Reference Images. Se seleccionan desde tu dispositivo local para la vista previa local y la organización del prompt.

Adjunta las mismas imágenes de referencia a la herramienta externa de IA en el orden exacto que aparece en Scene Director. Un cambio de orden puede hacer que la herramienta externa siga una fuente equivocada. Las ranuras vacías y las imágenes cuya función siga siendo Rol obligatorio se excluyen de Final Prompt y Compact Prompt.

Controles del prompt

La barra lateral incluye controles de Project Type, Character, Multi-Character, Camera, Pose, Face, Costume, Environment, Rendering y Additional Instructions. El cuadro de ayuda también incluye Reference Images, Final Prompt (en inglés) y Composition Preview.

Final Prompt es el prompt detallado en inglés generado a partir de la configuración actual. Por diseño, se mantiene únicamente en inglés y es más detallado que Compact Prompt. Scene Director no genera directamente la imagen final.

Sesiones y preajustes

Scene Director guarda automáticamente la sesión actual y la restaura al abrir la aplicación. La barra de estado muestra Auto saved y Last saved: just now.

Utiliza Save Preset para guardar el estado actual con un nombre. Load Preset restaura un preajuste guardado y Delete Preset lo elimina. Guardar con un nombre existente actualiza ese preajuste.

Utiliza New Prompt para restablecer el espacio de trabajo actual del prompt a sus valores predeterminados. Los preajustes guardados no se eliminan.

Los datos de la última sesión se guardan en %APPDATA%\Scene Director\last_session.json. Los preajustes se guardan en %APPDATA%\Scene Director\presets.json.

Plataforma y servicios externos

Scene Director está disponible actualmente para Windows. No es un servicio de generación de imágenes y no carga imágenes de referencia en otro servicio por ti. Tú eliges el servicio externo de generación de imágenes mediante IA y cargas allí las imágenes de referencia.
