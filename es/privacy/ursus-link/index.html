URSUS Link

Política de privacidad

Fecha de entrada en vigor: 24 de agosto de 2026

1. Descripción general

URSUS Link está operado por URSUS Loft. Permite que un remitente comparta archivos directamente desde su PC al navegador web del destinatario.

2. Información que procesa URSUS Link

Para ofrecer el uso compartido, la aplicación procesa la carpeta elegida por el remitente; los nombres, rutas, metadatos y contenidos de sus archivos; un token de Share Link; un PIN y datos de sesión del destinatario; información de red y conexión local; y datos de solicitudes y transferencias. Al elegir Copy Link, escribe el enlace generado en el portapapeles de Windows, pero no lee su contenido.

URSUS Link no tiene cuentas de usuario ni procesa directamente datos de tarjetas de pago. No incluye analítica publicitaria, seguimiento del comportamiento ni SDK publicitarios de terceros.

3. Archivos que comparte

URSUS Link accede a los archivos y carpetas elegidos por el remitente. Los archivos se envían directamente desde su PC al navegador del destinatario y no se cargan en un almacenamiento en la nube ni en un servicio de retransmisión de URSUS Loft.

Para descargar una carpeta o varios elementos, la aplicación puede crear un paquete ZIP64 local en el PC del remitente y servirlo directamente al destinatario.

4. Información de red y conexión

La aplicación puede procesar la dirección IP local, puerta de enlace predeterminada, estado de red o firewall de Windows, dirección IP pública y puerto de uso compartido para preparar y diagnosticar la conexión directa. También puede procesar temporalmente la IP del destinatario para limitar intentos de PIN y gestionar transferencias, junto con los datos de solicitud, Range, sesión y archivo necesarios para servir descargas.

Las IP de destinatarios, PIN, tokens de Share Link y valores de cookies de sesión no se conservan en los registros de diagnóstico.

5. Almacenamiento local

URSUS Link puede almacenar configuración, registros de diagnóstico rotativos, claves y certificados TLS/ACME generados localmente y archivos de caché ZIP en %LOCALAPPDATA%\URSUS Link. La configuración incluye la última carpeta compartida, el idioma y la preferencia al cerrar mientras se comparte.

Los registros permanecen en el equipo y no se envían automáticamente a URSUS Loft. Se ocultan las rutas completas de Windows, IP sin enmascarar, PIN, tokens, cookies de sesión y valores con apariencia de secreto.

6. Servicios de terceros

Para conocer la IP pública, la aplicación puede usar api.ipify.org, icanhazip.com o ifconfig.me. Estos servicios reciben la IP de conexión y el User-Agent y devuelven una IPv4 pública. No reciben el contenido compartido, PIN ni tokens de Share Link para esa consulta.

Para emitir o renovar certificados HTTPS, puede usar Let's Encrypt. Se envían las solicitudes y datos de validación necesarios; las claves privadas TLS y de la cuenta ACME permanecen en el PC del remitente. La aplicación también puede comunicarse con el router de la red local para preparar una conexión externa directa.

7. Seguridad de la conexión

URSUS Link normalmente intenta preparar un enlace HTTPS. Reintenta hasta tres veces ciertos fallos de configuración. Si no puede preparar HTTPS, el remitente puede elegir expresamente continuar con HTTP, reintentar HTTPS o cancelar. HTTP nunca se selecciona automáticamente.

Cuando se usa HTTP, los datos de esa sesión no están cifrados durante el tránsito.

8. Conservación de datos

Los datos de sesiones y transferencias activas se mantienen en memoria. Las sesiones de autenticación caducan tras ocho horas y el estado activo se borra al dejar de compartir. Los paquetes completados pueden limpiarse después de 24 horas y por límites de caché. Los registros rotan por tamaño, no por un plazo fijo en días.

Algunos ajustes, registros, material TLS y cachés pueden permanecer tras desinstalar. Puede eliminar manualmente %LOCALAPPDATA%\URSUS Link.

9. Comunicación de datos

Los archivos, nombres, listados y contenidos de carpetas o paquetes se entregan directamente a quienes usan el Share Link y completan el PIN requerido. Los servicios de IP pública y certificados solo reciben lo necesario para sus funciones. URSUS Loft no opera una nube de retransmisión ni almacenamiento para estas transferencias.

10. Sus opciones

Puede elegir la carpeta, cambiar o regenerar el PIN, detener el uso compartido y borrar los datos locales tras desinstalar. Al detenerlo, se cierra el servidor local y el Share Link activo deja de estar disponible.

11. Privacidad infantil

URSUS Link es una herramienta de intercambio de archivos y no incluye cuentas ni perfiles infantiles.

12. Cambios en esta política

URSUS Loft puede actualizar esta política cuando cambien las prácticas de datos de la aplicación. La fecha de entrada en vigor se actualizará al publicar una revisión.
