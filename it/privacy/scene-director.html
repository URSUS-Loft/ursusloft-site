Scene Director

Informativa sulla privacy

Scene Director è sviluppato, gestito e pubblicato da URSUS Loft.

Scene Director non gestisce account utente né server dello sviluppatore. L’app non trasmette immagini di riferimento, prompt, preset, dati di sessione o impostazioni del progetto a URSUS Loft o a un altro server esterno. Le immagini di riferimento vengono selezionate dal dispositivo locale dell’utente per l’anteprima locale e l’organizzazione del prompt.

I dati dell’ultima sessione e dei preset sono archiviati localmente in:
%APPDATA%\Scene Director
Questi file memorizzano testo e impostazioni, compresi i ruoli delle immagini di riferimento. Non memorizzano file di immagini di riferimento, nomi di file o percorsi. Eliminare i file locali rimuove le impostazioni salvate della sessione o dei preset. Il comportamento di rimozione o disinstallazione di Windows può variare, quindi la rimozione completa dei file AppData non è garantita.

Microsoft Store, Windows e qualsiasi servizio esterno di IA scelto dall’utente elaborano i dati secondo le proprie politiche. URSUS Loft non controlla questi servizi né il modo in cui elaborano i dati.

Le domande su questa Informativa sulla privacy possono essere inviate a support@ursusloft.com.
