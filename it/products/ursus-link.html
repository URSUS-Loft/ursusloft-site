URSUS Link

Condividi file e cartelle direttamente dal PC.

Acquista su Microsoft Store

Scegli la cartella che vuoi condividere e invia i file con un semplice link. URSUS Link consente di trasferire foto, video, materiali di lavoro e file di grandi dimensioni direttamente dal tuo PC Windows, senza caricarli prima su un servizio cloud separato.

È semplice: seleziona una cartella, avvia la condivisione e invia al destinatario il link generato e il PIN obbligatorio di quattro cifre. Chi riceve può visualizzare e scaricare i file da un browser compatibile senza acquistare o installare URSUS Link.

I file passano direttamente dal PC al browser del destinatario tramite HTTPS; gli originali non vengono archiviati su un server di file hosting separato. Puoi condividere file di grandi dimensioni, ma velocità e dimensioni gestibili dipendono dalla connessione, dal browser, dal computer e dallo spazio disponibile. Il PC mittente deve rimanere acceso e connesso durante la condivisione. Acquisto unico, nessun abbonamento.

Prima dell'acquisto: compatibilità di rete
La rete deve consentire connessioni HTTPS in ingresso direttamente al PC mittente. Alcuni router, firewall, restrizioni dell'operatore, doppio NAT o CGNAT possono impedirle. Se la configurazione automatica non basta e non puoi modificare le impostazioni di rete, la condivisione via Internet potrebbe non funzionare. URSUS Link non usa un server di inoltro file per garantire la connessione su tutte le reti. Verifica la compatibilità prima di acquistare.

Verifica gratuita della compatibilità

Windows 10/11 x64, gratuito e senza installazione. Stima la rete in sola lettura, senza modificare file o router; consulta un servizio IP pubblico esterno. La stima non garantisce la connessione. Windows 10 non testato su PC fisico.
