URSUS Link

Assistenza

Assistenza per condividere file direttamente da un PC Windows.

Per iniziare

URSUS Link condivide i file di una cartella del PC direttamente con il browser del destinatario. I file non vengono caricati in uno spazio cloud URSUS Loft.

  1. Scegli Shared Folder.
  2. Controlla o modifica la Password a quattro cifre.
  3. Seleziona Start Sharing.
  4. Attendi la creazione del Share Link.
  5. Invia Share Link e password al destinatario.
  6. Il destinatario apre il link, inserisce il PIN o la password e scarica i file.
  7. Al termine seleziona Stop Sharing.

Link di condivisione e download nel browser

Il destinatario non deve installare URSUS Link; basta un browser web aggiornato. Invia Share Link e password in privato e mantieni online il PC del mittente durante la condivisione.

HTTPS e fallback HTTP

URSUS Link prepara normalmente HTTPS e ripete fino a tre volte gli errori di configurazione idonei. Se HTTPS non è ancora disponibile, puoi scegliere esplicitamente il fallback HTTP. Quella sessione non sarà cifrata durante il trasferimento.

File di grandi dimensioni e condivisione in background

I file grandi vengono trasmessi dal disco e supportano richieste Range/ripresa. Il download di cartelle può usare un pacchetto ZIP64 locale temporaneo. URSUS Link può restare disponibile nell'area di notifica; mantieni app e PC accesi fino al termine.

Risoluzione dei problemi di connessione

Se il link non si apre, verifica che la condivisione sia attiva, copia di nuovo il link corrente e mantieni online il PC del mittente. Consenti l'accesso di Windows Firewall quando richiesto. Alcuni router, CGNAT e reti aziendali, pubbliche o mobili possono bloccare le connessioni dirette in ingresso.
