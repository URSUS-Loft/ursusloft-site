URSUS Link

Kebijakan Privasi

Tanggal berlaku: 24 Agustus 2026

1. Ringkasan

URSUS Link dioperasikan oleh URSUS Loft. Aplikasi ini memungkinkan pengirim membagikan file langsung dari PC pengirim ke browser web penerima.

2. Informasi yang Diproses

Untuk menyediakan berbagi file, aplikasi memproses folder yang dipilih pengirim; nama, jalur, metadata, dan isi file; token Share Link; PIN dan data sesi penerima; informasi jaringan serta koneksi lokal; dan informasi permintaan serta transfer. Saat Copy Link dipilih, aplikasi menulis tautan ke clipboard Windows, tetapi tidak membaca isi clipboard.

Tidak ada sistem akun dan aplikasi tidak memproses informasi kartu pembayaran secara langsung. Tidak ada analitik iklan, pelacakan perilaku, atau SDK iklan pihak ketiga.

3. File yang Anda Bagikan

URSUS Link mengakses file dan folder yang dipilih pengirim. File dikirim langsung dari PC pengirim ke browser penerima dan tidak diunggah ke penyimpanan cloud atau layanan relay URSUS Loft.

Untuk folder atau beberapa item, aplikasi dapat membuat paket ZIP64 lokal di PC pengirim dan menyajikannya langsung kepada penerima.

4. Informasi Jaringan dan Koneksi

Untuk menyiapkan dan mendiagnosis berbagi langsung, aplikasi dapat memproses IP lokal, gateway default, status jaringan atau firewall Windows, IP publik, dan port. Aplikasi dapat memproses sementara IP penerima untuk membatasi percobaan PIN dan menangani transfer, serta informasi permintaan, Range, sesi, dan file yang diperlukan.

IP penerima, PIN, token Share Link, dan cookie sesi tidak disimpan dalam log diagnostik.

5. Penyimpanan Lokal

Di %LOCALAPPDATA%\URSUS Link, aplikasi dapat menyimpan pengaturan, log diagnostik berotasi, kunci dan sertifikat TLS/ACME yang dibuat secara lokal, serta cache ZIP. Pengaturan mencakup folder terakhir, bahasa, dan preferensi penutupan saat berbagi.

Log tetap lokal dan tidak otomatis diunggah. Jalur Windows lengkap, IP mentah, PIN, token, cookie, dan nilai seperti rahasia disamarkan.

6. Layanan Pihak Ketiga

Untuk menentukan IP publik, aplikasi dapat menggunakan api.ipify.org, icanhazip.com, atau ifconfig.me. Layanan menerima IP koneksi dan User-Agent lalu mengembalikan IPv4 publik. File, PIN, dan token Share Link tidak dikirim untuk pencarian ini.

Untuk penerbitan atau pembaruan sertifikat HTTPS, aplikasi dapat menggunakan Let's Encrypt. Permintaan dan data validasi yang diperlukan dikirim; kunci pribadi TLS dan akun ACME tetap di PC pengirim. Aplikasi juga dapat berkomunikasi dengan router lokal untuk menyiapkan koneksi eksternal langsung.

7. Keamanan Koneksi

URSUS Link biasanya mencoba menyiapkan tautan HTTPS dan mencoba ulang hingga tiga kali untuk kegagalan tertentu. Jika HTTPS tidak tersedia, pengirim dapat secara tegas memilih melanjutkan dengan HTTP, mencoba HTTPS lagi, atau membatalkan. HTTP tidak pernah dipilih otomatis.

Saat HTTP digunakan, data sesi tersebut tidak dienkripsi selama transit.

8. Retensi Data

Data sesi dan transfer aktif disimpan di memori. Sesi autentikasi berakhir setelah delapan jam dan status aktif dibersihkan saat berbagi dihentikan. Paket selesai dapat dibersihkan setelah 24 jam dan berdasarkan ukuran cache. Log berotasi menurut ukuran.

Pengaturan, log, materi TLS, dan cache dapat tetap ada setelah uninstall. Anda dapat menghapus %LOCALAPPDATA%\URSUS Link secara manual.

9. Pembagian Data

File, nama, daftar, dan isi folder atau paket diberikan langsung kepada penerima yang menggunakan Share Link dan menyelesaikan PIN. Layanan IP dan sertifikat hanya menerima informasi yang diperlukan. URSUS Loft tidak mengoperasikan relay atau penyimpanan cloud untuk transfer URSUS Link.

10. Pilihan Anda

Anda dapat memilih folder, mengubah atau membuat ulang PIN, menghentikan berbagi, dan menghapus data lokal setelah uninstall. Menghentikan berbagi menutup server lokal dan membuat Share Link tidak tersedia.

11. Privasi Anak

URSUS Link adalah alat berbagi file dan tidak memiliki akun atau profil anak.

12. Perubahan Kebijakan

URSUS Loft dapat memperbarui kebijakan ini saat praktik data berubah. Tanggal berlaku akan diperbarui saat revisi diterbitkan.

13. Kontak

Kirim pertanyaan ke support@ursusloft.com.
