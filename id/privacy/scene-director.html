Kebijakan Privasi

Scene Director dikembangkan, dioperasikan, dan diterbitkan oleh URSUS Loft.

Scene Director tidak mengoperasikan akun pengguna atau server pengembang. Aplikasi tidak mengirimkan gambar referensi, prompt, preset, data sesi, atau pengaturan proyek kepada URSUS Loft maupun server eksternal lainnya. Gambar referensi dipilih dari perangkat lokal pengguna untuk pratinjau lokal dan penataan prompt.

Data sesi terakhir dan preset disimpan secara lokal di:
%APPDATA%\Scene Director
Berkas ini menyimpan teks dan pengaturan, termasuk peran gambar referensi. Berkas tersebut tidak menyimpan berkas gambar referensi, nama berkas, atau jalur berkas. Menghapus berkas lokal akan menghapus pengaturan sesi atau preset yang tersimpan. Perilaku penghapusan atau pencopotan Windows dapat berbeda-beda, sehingga penghapusan seluruh berkas AppData tidak dijamin.

Microsoft Store, Windows, dan layanan AI eksternal yang dipilih pengguna memproses data sesuai kebijakan masing-masing. URSUS Loft tidak mengendalikan layanan tersebut maupun cara layanan tersebut memproses data.

Pertanyaan mengenai Kebijakan Privasi ini dapat dikirim ke support@ursusloft.com.
