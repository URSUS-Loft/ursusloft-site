URSUS Link

Dukungan

Bantuan untuk berbagi file langsung dari PC Windows.

Memulai

URSUS Link membagikan file dari folder di PC Anda langsung ke browser penerima. File tidak diunggah ke penyimpanan cloud URSUS Loft.

  1. Pilih Shared Folder.
  2. Periksa atau ubah Password empat digit.
  3. Pilih Start Sharing.
  4. Tunggu hingga Share Link dibuat.
  5. Kirim Share Link dan kata sandi kepada penerima.
  6. Penerima membuka tautan, memasukkan PIN/kata sandi, lalu mengunduh file.
  7. Pilih Stop Sharing setelah selesai.

Tautan berbagi dan unduhan browser

Penerima tidak perlu memasang URSUS Link; browser web modern sudah cukup. Kirim Share Link dan kata sandi secara pribadi serta biarkan PC pengirim tetap online selama berbagi.

HTTPS dan fallback HTTP

URSUS Link biasanya menyiapkan HTTPS dan mencoba ulang kegagalan penyiapan yang memenuhi syarat hingga tiga kali. Jika HTTPS masih tidak dapat disiapkan, Anda dapat memilih fallback HTTP secara tegas. Sesi tersebut tidak dienkripsi selama pengiriman.

File besar dan berbagi di latar belakang

File besar dialirkan dari disk serta mendukung permintaan Range/lanjutkan. Unduhan folder dapat memakai paket ZIP64 lokal sementara. URSUS Link dapat tetap tersedia dari baki sistem; biarkan aplikasi dan PC menyala sampai transfer selesai.

Pemecahan masalah koneksi

Jika tautan tidak dapat dibuka, pastikan berbagi masih aktif, salin ulang tautan terkini, dan biarkan PC pengirim tetap online. Izinkan akses Windows Firewall saat diminta. Beberapa router, CGNAT, serta jaringan perusahaan, publik, atau seluler dapat memblokir koneksi langsung yang masuk.
