Persona Director

Dukungan

Panduan alur kerja Persona Director saat ini di Windows.

Memulai

Persona Director adalah aplikasi Windows lokal untuk mendesain satu karakter fiksi dan membuat prompt terstruktur. Atur karakter, pilih keluaran, lalu tinjau dan salin prompt.

Desain karakter

Gunakan kontrol identitas, wajah, rambut, tubuh, pakaian, dan latar belakang yang terpisah untuk mengatur satu persona. Persona Director menyiapkan arahan karakter; aplikasi ini tidak menghasilkan gambar.

Prompt dan keluaran

Pilih Single Portrait, Full Body, atau Character Sheet, pilih profil AI gambar dan gaya pengambilan, lalu tinjau dan salin prompt terstruktur dari konfigurasi saat ini.

Pertanyaan umum

Persona Director berjalan secara lokal di Windows dan menyiapkan prompt untuk layanan eksternal atau alur kerja model lokal. Nama model menunjukkan target prompt dan tidak menyiratkan afiliasi.
