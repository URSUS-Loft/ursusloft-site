URSUS Loft · Windows 10 / 11

URSUS Link

Bagikan berkas dan folder langsung dari PC.

Dapatkan di Microsoft Store

Pilih folder yang ingin dibagikan, lalu kirim file melalui satu tautan sederhana. URSUS Link membantu mengirim foto, video, berkas pekerjaan, dan file berukuran besar langsung dari PC Windows tanpa harus mengunggahnya terlebih dahulu ke penyimpanan cloud terpisah.

Caranya mudah: pilih folder, mulai berbagi, lalu kirim tautan yang dibuat beserta PIN empat digit yang wajib digunakan. Penerima dapat melihat dan mengunduh file melalui browser yang didukung tanpa membeli atau memasang URSUS Link.

File ditransfer langsung dari PC pengirim ke browser penerima melalui HTTPS; file asli tidak disimpan di server penyimpanan terpisah. Cocok juga untuk file besar, tetapi kecepatan dan ukuran yang dapat ditangani bergantung pada koneksi, browser, perangkat, serta ruang penyimpanan. PC pengirim harus tetap menyala dan terhubung ke internet selama berbagi. Cukup sekali beli, tanpa langganan.

Sebelum membeli: kompatibilitas jaringan
Jaringan harus mengizinkan koneksi HTTPS dari luar langsung ke PC pengirim. Router, firewall, batasan penyedia internet, NAT ganda, atau CGNAT dapat menghalangi koneksi. Jika pengaturan otomatis tidak berhasil dan pengaturan jaringan tidak dapat diubah, berbagi lewat internet mungkin tidak berfungsi. URSUS Link tidak menggunakan server relay file untuk menjamin koneksi di semua jaringan. Periksa kompatibilitas sebelum membeli.

Pemeriksaan kompatibilitas jaringan gratis

Windows 10/11 x64, gratis tanpa instalasi. Memperkirakan jaringan secara baca-saja tanpa mengubah berkas atau router; menggunakan layanan IP publik eksternal. Hasil tidak menjamin koneksi. Windows 10 belum diuji pada PC fisik.
