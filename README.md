# URSUS Loft official website

Static HTML, CSS, and JavaScript for the URSUS Loft website. It is designed for GitHub Pages and the official domain is `ursusloft.com`.

## Structure

- `index.html` — company homepage
- `products/` — product pages
- `privacy/`, `support/`, `legal/` — Scene Director documents
- `assets/` — shared styles, script, and supplied image assets

## Local preview

Open `index.html` directly, or run a simple local server from the repository root:

```text
python -m http.server 8000
```

Then visit `http://localhost:8000`.
