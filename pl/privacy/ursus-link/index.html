URSUS Link

Polityka prywatności

Data wejścia w życie: 24 sierpnia 2026 r.

1. Informacje ogólne

URSUS Link jest obsługiwany przez URSUS Loft. Umożliwia nadawcy udostępnianie plików bezpośrednio z własnego komputera do przeglądarki internetowej odbiorcy.

2. Informacje przetwarzane przez URSUS Link

Aby zapewnić udostępnianie, aplikacja przetwarza folder wybrany przez nadawcę; nazwy, ścieżki, metadane i zawartość plików; token Share Link; PIN i dane sesji odbiorcy; lokalne informacje sieciowe i połączenia; oraz dane żądań i transferów. Po wybraniu Copy Link aplikacja zapisuje link w schowku Windows, lecz nie odczytuje jego zawartości.

URSUS Link nie ma systemu kont i nie przetwarza bezpośrednio danych kart płatniczych. Nie zawiera analityki reklamowej, śledzenia zachowania ani zewnętrznych SDK reklamowych.

3. Udostępniane pliki

URSUS Link uzyskuje dostęp do plików i folderów wybranych przez nadawcę. Są one przesyłane bezpośrednio z komputera nadawcy do przeglądarki odbiorcy, bez wysyłania do chmury lub przekaźnika URSUS Loft.

Dla folderu lub wielu elementów aplikacja może utworzyć lokalny pakiet ZIP64 na komputerze nadawcy i podać go bezpośrednio odbiorcy.

4. Informacje sieciowe i połączenia

Do przygotowania i diagnostyki połączenia aplikacja może przetwarzać lokalny adres IP, bramę domyślną, stan sieci lub zapory Windows, publiczny adres IP i port. Może tymczasowo przetwarzać IP odbiorcy w celu ograniczania prób PIN i obsługi transferów, wraz z potrzebnymi danymi żądania, Range, sesji i pliku.

Adresy IP odbiorców, PIN, tokeny Share Link i wartości cookies sesji nie są przechowywane w logach diagnostycznych.

5. Lokalne przechowywanie danych

W %LOCALAPPDATA%\URSUS Link aplikacja może przechowywać ustawienia, rotowane logi, lokalnie wygenerowane klucze i certyfikaty TLS/ACME oraz cache ZIP. Ustawienia obejmują ostatni folder, język i preferencję zamykania podczas udostępniania.

Logi pozostają lokalnie i nie są automatycznie przesyłane do URSUS Loft. Pełne ścieżki Windows, surowe IP, PIN, tokeny, cookies i wartości podobne do sekretów są maskowane.

6. Usługi zewnętrzne

Do ustalenia publicznego IP aplikacja może używać api.ipify.org, icanhazip.com lub ifconfig.me. Usługi otrzymują IP połączenia i User-Agent, a zwracają publiczny IPv4. Pliki, PIN i token Share Link nie są im wysyłane.

Do wydania lub odnowienia certyfikatu HTTPS może być używany Let's Encrypt. Wysyłane są niezbędne żądania i dane weryfikacyjne; prywatne klucze TLS i konta ACME pozostają na komputerze nadawcy. Aplikacja może też komunikować się z lokalnym routerem w celu przygotowania bezpośredniego połączenia zewnętrznego.

7. Bezpieczeństwo połączenia

URSUS Link zwykle próbuje przygotować link HTTPS i ponawia odpowiednie błędy do trzech razy. Jeśli HTTPS nie jest możliwy, nadawca może wyraźnie wybrać kontynuację przez HTTP, ponowienie HTTPS lub anulowanie. HTTP nigdy nie jest wybierany automatycznie.

Przy HTTP dane tej sesji nie są szyfrowane podczas przesyłania.

8. Okres przechowywania

Dane aktywnych sesji i transferów znajdują się w pamięci. Sesje uwierzytelniania wygasają po ośmiu godzinach, a stan aktywny jest usuwany po zatrzymaniu udostępniania. Gotowe pakiety mogą być usunięte po 24 godzinach i w ramach czyszczenia cache. Logi rotują według rozmiaru.

Niektóre ustawienia, logi, dane TLS i cache mogą pozostać po odinstalowaniu. Można ręcznie usunąć %LOCALAPPDATA%\URSUS Link.

9. Udostępnianie danych

Pliki, nazwy, listy i zawartość folderów lub pakietów są przekazywane bezpośrednio odbiorcom korzystającym z Share Link i kończącym wymagany krok PIN. Usługi IP i certyfikatów otrzymują wyłącznie niezbędne informacje. URSUS Loft nie prowadzi chmurowego przekaźnika ani magazynu dla transferów URSUS Link.

10. Twoje wybory

Możesz wybrać folder, zmienić lub wygenerować PIN, zatrzymać udostępnianie i usunąć lokalne dane po odinstalowaniu. Zatrzymanie zamyka lokalny serwer i wyłącza aktywny Share Link.

11. Prywatność dzieci

URSUS Link jest narzędziem do udostępniania plików i nie zawiera kont ani profili dzieci.

12. Zmiany polityki

URSUS Loft może aktualizować politykę, gdy zmienią się praktyki dotyczące danych. Data wejścia w życie zostanie zmieniona przy publikacji.

13. Kontakt

Pytania prosimy wysyłać na support@ursusloft.com.
