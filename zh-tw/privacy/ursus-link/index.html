URSUS Link

隱私權政策

生效日期：2026年8月24日

1. 概述

URSUS Link 由 URSUS Loft 營運。它讓傳送者將檔案從自己的電腦直接分享至接收者的網頁瀏覽器。

2. URSUS Link 處理的資訊

為提供分享功能，應用程式會處理傳送者選擇的資料夾、其中的檔案名稱、路徑、中繼資料與內容、Share Link 權杖、PIN 與接收者工作階段資料、本機網路與連線資訊，以及接收者的請求和傳輸資訊。選擇 Copy Link 時，應用程式會將產生的連結寫入 Windows 剪貼簿，但不會讀取剪貼簿內容。

URSUS Link 沒有使用者帳戶系統，也不直接處理付款卡資訊。它不包含廣告分析、行為追蹤或第三方廣告 SDK。

3. 您分享的檔案

應用程式會存取傳送者選擇用於分享的檔案與資料夾。檔案從傳送者電腦直接傳送至接收者瀏覽器，不會上傳到 URSUS Loft 雲端儲存空間或中繼服務。

下載資料夾或多個項目時，應用程式可能在傳送者電腦上建立本機 ZIP64 套件。該套件包含所選分享內容，並直接提供給接收者。

4. 網路與連線資訊

為準備和診斷直接分享，應用程式可能處理本機 IP 位址、預設閘道、Windows 網路或防火牆狀態、公網 IP 位址及分享連接埠。為暫時限制 PIN 嘗試次數和處理進行中的傳輸，可能處理接收者 IP 位址，以及提供下載所需的請求、Range、工作階段和要求檔案資訊。

接收者 IP 位址、PIN、Share Link 權杖和工作階段 Cookie 值不會保留在診斷記錄中。

5. 本機資料儲存

應用程式可能在 %LOCALAPPDATA%\URSUS Link 儲存設定、輪替診斷記錄、本機產生的 TLS/ACME 金鑰與憑證，以及 ZIP/套件快取。設定包括上次選擇的分享資料夾路徑、語言和分享期間關閉視窗的偏好。

診斷記錄保存在本機，不會自動上傳至 URSUS Loft。格式化記錄會遮蔽完整 Windows 路徑、原始用戶端 IP、PIN、權杖、工作階段 Cookie 和類似機密的值。

6. 第三方服務

應用程式可能使用 api.ipify.org、icanhazip.com 或 ifconfig.me 查詢公網 IP。這些服務會收到請求連線 IP 和應用程式 User-Agent，並傳回公網 IPv4。分享檔案內容、PIN 和 Share Link 權杖不會為此查詢而傳送。

應用程式可能使用 Let's Encrypt 簽發或更新 HTTPS 憑證。必要的憑證請求與驗證資訊會被傳送；TLS 私密金鑰和 ACME 帳戶私密金鑰保留在傳送者電腦上。應用程式也可能與傳送者區域網路路由器通訊，以準備直接外部連線。

7. 連線安全

URSUS Link 通常會嘗試準備 HTTPS 連結。對於符合條件的 HTTPS 設定失敗，最多重試三次。若無法準備 HTTPS，傳送者可以明確選擇繼續使用 HTTP、重試 HTTPS 或取消。應用程式絕不會自動選擇 HTTP。

使用 HTTP 時，該分享工作階段中傳輸的資料不會在傳輸過程中加密。

8. 資料保留

進行中的分享工作階段和傳輸資料保留在記憶體中。接收者驗證工作階段八小時後到期，停止分享時會清除進行中的工作階段狀態。已完成的套件檔案可在24小時後及快取大小清理時刪除。記錄依大小輪替，而非依固定天數保留。

解除安裝後，部分本機設定、記錄、TLS 資料和快取可能仍然存在。若要移除，可在解除安裝後手動刪除 %LOCALAPPDATA%\URSUS Link。

9. 資料分享

分享檔案、檔名、清單及資料夾/套件內容會直接提供給使用 Share Link 並完成所需 PIN 步驟的接收者。上述公網 IP 查詢與憑證服務只會收到提供其服務所需的資訊。URSUS Loft 不營運用於 URSUS Link 檔案傳輸的雲端中繼或儲存服務。

10. 您的選擇

您可以選擇分享資料夾、變更或重新產生 PIN、停止分享，並在解除安裝後刪除本機應用程式資料。停止分享會關閉本機分享伺服器，使目前 Share Link 無法使用。

11. 兒童隱私

URSUS Link 是檔案分享工具，不包含兒童帳戶或個人資料。

12. 政策變更

當應用程式的資料處理方式改變時，URSUS Loft 可能更新本政策。修訂政策發布時會更新生效日期。

13. 聯絡方式

如對本政策有疑問，請聯絡 support@ursusloft.com。
