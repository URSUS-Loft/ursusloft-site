URSUS Link

從電腦直接分享檔案和資料夾。

在 Microsoft Store 取得

選擇想分享的資料夾，用一個連結就能輕鬆分享檔案。URSUS Link 讓你直接從 Windows 電腦傳送相片、影片、工作資料及大型檔案，不必先上傳至其他雲端儲存服務。

使用方式很簡單：選擇資料夾、開始分享，再將產生的連結與必要的四位數 PIN 碼交給接收者。對方不需要購買或安裝 URSUS Link，只要使用支援的瀏覽器，就能檢視及下載分享的檔案。

檔案透過 HTTPS，從傳送端電腦直接傳至接收者的瀏覽器；原始檔案不會預先存放在獨立的檔案託管伺服器。適合分享大型檔案，但實際速度與可處理的大小仍取決於網路、瀏覽器、電腦效能及儲存空間。分享期間，傳送端電腦必須保持開機及連線。一次購買，無須訂閱。

購買前請注意網路相容性
此應用程式需要外部網路可透過 HTTPS 直接連線至傳送端電腦。路由器、防火牆、網路業者限制、雙重 NAT 或 CGNAT 等情況可能造成連線失敗。若自動設定無法解決，且無法變更路由器或網路設定，就可能無法透過網際網路分享。URSUS Link 不會以檔案中繼伺服器保證所有網路都能連線。購買前請確認網路支援直接連線。
