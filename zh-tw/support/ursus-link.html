支援

協助您直接從 Windows 電腦分享檔案。

從電腦直接分享檔案和資料夾。 僅私下向信任的人傳送連結與密碼。

開始分享

選擇分享資料夾旁的「變更」，選擇包含檔案的資料夾，確認四位密碼後開始分享。連結出現後複製連結並連同密碼傳給接收者。對方在瀏覽器開啟連結、輸入密碼，再下載需要的檔案或資料夾。完成後停止分享。

連結無法開啟

確認傳送電腦已開機、連網、未睡眠且仍在分享。再次傳送目前連結和密碼，並檢查接收者網路。重新分享或網路變更後連結改變時，請傳送新連結。顯示連結不代表對方已成功連線。仍失敗時請查看以下防火牆和路由器說明。

連線狀態中，灰色表示等待或準備，紅色表示錯誤。藍色表示 HTTPS 分享已準備好，但外部存取尚未確認；綠色表示已觀察到通過驗證的外部請求。僅產生連結不能證明外部可存取。

安全連線

應用程式會準備加密的 HTTPS 連線。網路或憑證服務可能導致準備失敗。瀏覽器出現安全警告時，請檢查連結和電腦日期時間；不要忽略警告或關閉保護。

密碼與驗證

向接收者提供目前四位密碼。失敗時檢查數字和最新連結。瀏覽器驗證到期時，確認分享仍在執行並用目前密碼重新驗證。變更密碼前先停止分享，變更後重新開始並傳送目前連結和密碼。

下載問題

下載中斷時，檢查傳送電腦和分享是否執行、接收者儲存空間和網路是否足夠，再於瀏覽器重試。資料夾 ZIP 也需要傳送電腦有暫存檔空間。能否續傳取決於瀏覽器和網路，無法保證；必要時從頭下載。

Windows 防火牆

準備分享時 Windows 可能要求管理員核准。核准後應用程式會嘗試準備所需防火牆規則。拒絕或管理原則可能限制直接連線。在 Windows 安全性檢查作用中網路和允許的應用程式；工作或學校電腦請詢問管理員。不要關閉整個防火牆。

路由器和網路限制

條件允許時應用程式會自動準備路由器連線。多台路由器或業者、工作、學校、公共網路封鎖連入可能導致失敗，但不能僅憑網路名稱判定無法使用。出現復原提示時，只檢查自己管理的路由器；需要手動設定和本次分享授權時依畫面操作。設定不保證連線成功。IPv6 也取決於雙方網路。尚未確認時可嘗試其他網路或詢問管理員。如果所有支援的直接連線路徑均被封鎖且無法變更，本產品無法解決該環境，不建議購買或使用。

出現 IPv4 手動復原畫面時，在自己管理的路由器轉送畫面所示檔案埠。僅在畫面要求時設定憑證 TCP 80 規則。完成必要設定後確認。仍需另行檢查外部存取。

維持分享和設定

分享時保持傳送電腦和網路開啟。關閉視窗時可選擇在系統匣繼續執行；系統匣可開啟視窗、複製連結、停止分享或結束。停止分享或結束可安全終止存取。語言和外觀可在應用程式畫面變更。

Microsoft Store

Microsoft Store 版本開始新分享前可能需要驗證有效授權。驗證中或失敗時，確認 Store 使用取得應用程式的帳戶登入，稍後再次開始分享。試用或退款條件請查看購買時顯示的 Microsoft Store 條款。

需要更多協助

請記錄分享狀態、錯誤發生時間及 Windows 和應用程式版本。可複製記錄以準備診斷資料。資料可能包含電腦或網路資訊；傳送前請移除密碼、PIN、分享連結、權杖和私密金鑰。
