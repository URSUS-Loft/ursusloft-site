協助您直接從 Windows 電腦分享檔案。

開始使用

URSUS Link 會將電腦所選資料夾中的檔案直接分享至接收者的瀏覽器。檔案不會上傳至 URSUS Loft 雲端儲存空間。

  1. 選擇 Shared Folder。
  2. 確認或變更四位數 Password。
  3. 選擇 Start Sharing。
  4. 等待 Share Link 建立完成。
  5. 將 Share Link 與密碼傳送給接收者。
  6. 接收者開啟連結、輸入 PIN／密碼並下載檔案。
  7. 完成後選擇 Stop Sharing。

分享連結與瀏覽器下載

接收者不需要安裝 URSUS Link，只要使用現代網頁瀏覽器即可。請私下傳送 Share Link 與密碼，並在分享期間讓傳送端電腦保持連線。

HTTPS 與 HTTP fallback

URSUS Link 通常會準備 HTTPS，並在符合條件的設定失敗時最多重試三次。若仍無法準備 HTTPS，使用者可以明確選擇 HTTP fallback；該分享工作階段的傳輸不會加密。

大型檔案與背景分享

大型檔案會從磁碟串流傳輸，並支援 Range／續傳要求。下載資料夾時可能會使用本機暫存 ZIP64 封裝。分享期間 URSUS Link 可在系統匣中繼續執行；請保持應用程式與電腦運作直到傳輸完成。

連線疑難排解

若連結無法開啟，請確認分享仍在進行、重新複製目前連結，並讓傳送端電腦保持連線。系統提示時請允許 Windows Firewall 存取。部分路由器、CGNAT、企業、公用或行動網路可能會封鎖直接連入連線。
