目前 Windows 版 Scene Director 工作流程指南。

開始使用

Scene Director 是外部 AI 影像生成工具的本機提示詞草擬與場景指導程式。它會整理參考影像角色、場景方向及英文 Final Prompt 或 Compact Prompt。

  1. 選擇 Project Type。
  2. 加入最多五張 Reference Images，並為要使用的影像指定清楚角色。
  3. 設定 Character、Camera、Pose、Face、Costume、Environment、Rendering 與 Additional Instructions。
  4. 檢視 Final Prompt 或 Compact Prompt。
  5. 將提示詞複製到外部 AI 影像生成工具，並依相同順序附加同一批參考影像。

參考影像與角色

Scene Director 不會上傳或分析 Reference Images。影像從本機裝置選取，只用於本機預覽與提示詞整理。請依應用程式顯示的確切順序，把同一批影像附加到外部工具。空白位置與仍標示 Role Required 的影像不會納入提示詞。

提示詞控制

側邊欄提供 Project Type、Character、Multi-Character、Camera、Pose、Face、Costume、Environment、Rendering 與 Additional Instructions。Final Prompt 是依目前設定產生的詳細英文提示詞；它依設計保持英文，且比 Compact Prompt 更完整。Scene Director 不會直接生成最終影像。

工作階段與預設

Scene Director 會自動儲存目前工作階段，並在開啟時還原。使用 Save Preset 依名稱儲存狀態；Load Preset 還原預設，Delete Preset 刪除預設。New Prompt 只重設目前工作區，不會刪除已儲存預設。

上次工作階段與預設儲存在 %APPDATA%\Scene Director。

平台與外部服務

Scene Director 目前支援 Windows。它不是影像生成服務，也不會代您上傳參考影像。您自行選擇外部服務並在該處上傳影像。
