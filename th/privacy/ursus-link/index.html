URSUS Link

นโยบายความเป็นส่วนตัว

วันที่มีผล: 24 สิงหาคม 2026

1. ภาพรวม

URSUS Link ดำเนินงานโดย URSUS Loft และช่วยให้ผู้ส่งแบ่งปันไฟล์จาก PC ของผู้ส่งไปยังเว็บเบราว์เซอร์ของผู้รับโดยตรง

2. ข้อมูลที่ URSUS Link ประมวลผล

เพื่อให้บริการแบ่งปัน แอปประมวลผลโฟลเดอร์ที่ผู้ส่งเลือก ชื่อไฟล์ เส้นทาง เมทาดาทาและเนื้อหา token ของ Share Link, PIN และข้อมูลเซสชันผู้รับ ข้อมูลเครือข่ายและการเชื่อมต่อในเครื่อง รวมถึงข้อมูลคำขอและการโอน เมื่อเลือก Copy Link แอปจะเขียนลิงก์ลงในคลิปบอร์ด Windows แต่ไม่อ่านเนื้อหาในคลิปบอร์ด

URSUS Link ไม่มีระบบบัญชีผู้ใช้และไม่ประมวลผลข้อมูลบัตรชำระเงินโดยตรง ไม่มีการวิเคราะห์โฆษณา การติดตามพฤติกรรม หรือ SDK โฆษณาของบุคคลที่สาม

3. ไฟล์ที่คุณแบ่งปัน

แอปเข้าถึงไฟล์และโฟลเดอร์ที่ผู้ส่งเลือก ไฟล์ถูกส่งตรงจาก PC ของผู้ส่งไปยังเบราว์เซอร์ของผู้รับ ไม่ได้อัปโหลดไปยังที่เก็บข้อมูล cloud หรือบริการ relay ของ URSUS Loft

สำหรับโฟลเดอร์หรือหลายรายการ แอปอาจสร้างแพ็กเกจ ZIP64 ในเครื่องของผู้ส่งและส่งให้ผู้รับโดยตรง

4. ข้อมูลเครือข่ายและการเชื่อมต่อ

เพื่อเตรียมและวินิจฉัยการแบ่งปันโดยตรง แอปอาจประมวลผล IP ในเครื่อง default gateway สถานะเครือข่ายหรือ firewall ของ Windows, IP สาธารณะ และพอร์ต แอปอาจประมวลผล IP ผู้รับชั่วคราวเพื่อจำกัดการลอง PIN และจัดการการโอน พร้อมข้อมูลคำขอ Range เซสชัน และไฟล์ที่จำเป็น

IP ผู้รับ, PIN, token Share Link และ cookie เซสชันจะไม่ถูกเก็บไว้ใน log วินิจฉัย

5. การจัดเก็บข้อมูลในเครื่อง

แอปอาจเก็บการตั้งค่า log แบบหมุนเวียน กุญแจและใบรับรอง TLS/ACME ที่สร้างในเครื่อง และ cache ZIP ที่ %LOCALAPPDATA%\URSUS Link การตั้งค่ารวมโฟลเดอร์ล่าสุด ภาษา และค่าการปิดขณะแบ่งปัน

Log อยู่ในเครื่องและไม่อัปโหลดไปยัง URSUS Loft โดยอัตโนมัติ เส้นทาง Windows แบบเต็ม IP ดิบ PIN token cookie และค่าที่คล้ายความลับจะถูกปกปิด

6. บริการของบุคคลที่สาม

แอปอาจใช้ api.ipify.org, icanhazip.com หรือ ifconfig.me เพื่อหา IP สาธารณะ บริการเหล่านี้รับ IP การเชื่อมต่อและ User-Agent แล้วส่งกลับ IPv4 สาธารณะ โดยไม่รับไฟล์ PIN หรือ token Share Link

แอปอาจใช้ Let's Encrypt เพื่อออกหรือต่ออายุใบรับรอง HTTPS โดยส่งเฉพาะคำขอและข้อมูลตรวจสอบที่จำเป็น กุญแจส่วนตัว TLS และบัญชี ACME อยู่บน PC ผู้ส่ง แอปอาจสื่อสารกับ router ในเครือข่ายท้องถิ่นเพื่อเตรียมการเชื่อมต่อภายนอกโดยตรง

7. ความปลอดภัยของการเชื่อมต่อ

URSUS Link จะพยายามเตรียมลิงก์ HTTPS ตามปกติและลองใหม่สูงสุดสามครั้งสำหรับข้อผิดพลาดที่เกี่ยวข้อง หากเตรียม HTTPS ไม่ได้ ผู้ส่งสามารถเลือกอย่างชัดเจนว่าจะใช้ HTTP ต่อ ลอง HTTPS ใหม่ หรือยกเลิก ระบบจะไม่เลือก HTTP โดยอัตโนมัติ

เมื่อใช้ HTTP ข้อมูลในเซสชันนั้นจะไม่เข้ารหัสระหว่างการส่ง

8. การเก็บรักษาข้อมูล

ข้อมูลเซสชันและการโอนที่ทำงานอยู่เก็บในหน่วยความจำ เซสชันยืนยันตัวตนหมดอายุหลังแปดชั่วโมงและสถานะถูกล้างเมื่อหยุดแบ่งปัน แพ็กเกจที่เสร็จแล้วอาจถูกล้างหลัง 24 ชั่วโมงและตามขนาด cache ส่วน log หมุนเวียนตามขนาด

การตั้งค่า log ข้อมูล TLS และ cache บางส่วนอาจคงอยู่หลังถอนการติดตั้ง คุณสามารถลบ %LOCALAPPDATA%\URSUS Link ด้วยตนเอง

9. การแบ่งปันข้อมูล

ไฟล์ ชื่อ รายการ และเนื้อหาโฟลเดอร์หรือแพ็กเกจส่งตรงไปยังผู้รับที่ใช้ Share Link และผ่านขั้นตอน PIN บริการ IP และใบรับรองรับเฉพาะข้อมูลที่จำเป็น URSUS Loft ไม่มี cloud relay หรือที่เก็บข้อมูลสำหรับการโอน URSUS Link

10. ตัวเลือกของคุณ

คุณเลือกโฟลเดอร์ เปลี่ยนหรือสร้าง PIN ใหม่ หยุดแบ่งปัน และลบข้อมูลในเครื่องหลังถอนการติดตั้งได้ การหยุดจะแจ้งปิดเซิร์ฟเวอร์ในเครื่องและทำให้ Share Link ใช้ไม่ได้

11. ความเป็นส่วนตัวของเด็ก

URSUS Link เป็นเครื่องมือแบ่งปันไฟล์และไม่มีบัญชีหรือโปรไฟล์สำหรับเด็ก

12. การเปลี่ยนแปลงนโยบาย

URSUS Loft อาจอัปเดตนโยบายเมื่อวิธีปฏิบัติต่อข้อมูลเปลี่ยนแปลง และจะอัปเดตวันที่มีผลเมื่อเผยแพร่
