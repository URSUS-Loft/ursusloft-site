Scene Director

ฝ่ายสนับสนุน

คำแนะนำสำหรับขั้นตอน Scene Director ปัจจุบันบน Windows

เริ่มต้นใช้งาน

Scene Director คือเครื่องมือบนเครื่องสำหรับร่างพรอมต์และกำกับฉากเพื่อใช้กับเครื่องมือสร้างภาพ AI ภายนอก

  1. เลือก Project Type
  2. เพิ่ม Reference Images ได้สูงสุดห้าภาพและกำหนดบทบาท
  3. ตั้งค่า Character, Camera, Pose, Face, Costume, Environment, Rendering และ Additional Instructions
  4. ตรวจ Final Prompt หรือ Compact Prompt
  5. คัดลอกพรอมต์และแนบภาพชุดเดิมตามลำดับเดียวกันในบริการภายนอก

ภาพอ้างอิงและบทบาท

Scene Director ไม่อัปโหลดหรือวิเคราะห์ภาพ ภาพถูกเลือกจากอุปกรณ์เพื่อดูตัวอย่างและจัดพรอมต์บนเครื่องเท่านั้น ช่องว่างและภาพ Role Required จะไม่รวมในผลลัพธ์

ตัวควบคุมพรอมต์

Final Prompt คือพรอมต์ภาษาอังกฤษแบบละเอียดจากการตั้งค่าปัจจุบัน และละเอียดกว่า Compact Prompt แอปไม่สร้างภาพสุดท้ายโดยตรง

เซสชันและพรีเซ็ต

แอปบันทึกเซสชันปัจจุบันและกู้คืนเมื่อเปิด ใช้ Save Preset, Load Preset, Delete Preset และ New Prompt ตามต้องการ ข้อมูลเก็บบนเครื่องใน %APPDATA%\Scene Director

แพลตฟอร์มและบริการภายนอก

Scene Director ใช้กับ Windows และไม่อัปโหลดภาพให้คุณ คุณเลือกบริการภายนอกและอัปโหลดภาพด้วยตนเอง
