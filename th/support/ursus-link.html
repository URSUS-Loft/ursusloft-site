ฝ่ายสนับสนุน

วิธีแชร์ไฟล์โดยตรงจากพีซี Windows

เริ่มต้นใช้งาน

URSUS Link แชร์ไฟล์จากโฟลเดอร์ที่เลือกบนพีซีไปยังเบราว์เซอร์ของผู้รับโดยตรง โดยไม่อัปโหลดไฟล์ไปยังพื้นที่เก็บข้อมูลคลาวด์ของ URSUS Loft

  1. เลือก Shared Folder
  2. ตรวจสอบหรือเปลี่ยน Password 4 หลัก
  3. เลือก Start Sharing
  4. รอให้สร้าง Share Link
  5. ส่ง Share Link และรหัสผ่านให้ผู้รับ
  6. ผู้รับเปิดลิงก์ ป้อน PIN/รหัสผ่าน แล้วดาวน์โหลดไฟล์
  7. เมื่อเสร็จแล้วให้เลือก Stop Sharing

ลิงก์แชร์และการดาวน์โหลดในเบราว์เซอร์

ผู้รับไม่ต้องติดตั้ง URSUS Link เพียงมีเว็บเบราว์เซอร์รุ่นใหม่ ส่ง Share Link และรหัสผ่านเป็นการส่วนตัว และให้พีซีของผู้ส่งออนไลน์อยู่ระหว่างการแชร์

HTTPS และการใช้ HTTP สำรอง

โดยปกติ URSUS Link จะเตรียม HTTPS และลองใหม่สำหรับข้อผิดพลาดที่เข้าเงื่อนไขสูงสุดสามครั้ง หากยังเตรียม HTTPS ไม่ได้ ผู้ใช้สามารถเลือกใช้ HTTP สำรองอย่างชัดเจนได้ เซสชันนั้นจะไม่เข้ารหัสข้อมูลระหว่างส่ง

ไฟล์ขนาดใหญ่และการแชร์เบื้องหลัง

ไฟล์ขนาดใหญ่จะสตรีมจากดิสก์และรองรับคำขอ Range/ทำต่อ การดาวน์โหลดโฟลเดอร์อาจใช้แพ็กเกจ ZIP64 ชั่วคราวในเครื่อง URSUS Link ทำงานต่อจากถาดระบบได้ระหว่างแชร์ โปรดเปิดแอปและพีซีไว้จนกว่าจะถ่ายโอนเสร็จ

แก้ไขปัญหาการเชื่อมต่อ

หากเปิดลิงก์ไม่ได้ ให้ตรวจสอบว่ากำลังแชร์อยู่ คัดลอกลิงก์ปัจจุบันอีกครั้ง และให้พีซีผู้ส่งออนไลน์ อนุญาต Windows Firewall เมื่อระบบถาม เราเตอร์บางรุ่น, CGNAT หรือเครือข่ายองค์กร สาธารณะ และมือถืออาจปิดกั้นการเชื่อมต่อขาเข้าโดยตรง
