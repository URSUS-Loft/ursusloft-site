วิธีแชร์ไฟล์โดยตรงจากพีซี Windows

แชร์ไฟล์และโฟลเดอร์จากพีซีโดยตรง ส่งลิงก์และรหัสผ่านแบบส่วนตัวให้เฉพาะคนที่คุณไว้วางใจ

เริ่มแชร์

เลือกเปลี่ยนข้างโฟลเดอร์แชร์ เลือกโฟลเดอร์ที่มีไฟล์ ตรวจสอบรหัสผ่านสี่หลัก แล้วเริ่มแชร์ คัดลอกลิงก์ที่ปรากฏและส่งพร้อมรหัสผ่าน ผู้รับเปิดลิงก์ในเบราว์เซอร์ ใส่รหัสผ่าน แล้วดาวน์โหลดไฟล์หรือโฟลเดอร์ เมื่อเสร็จให้หยุดแชร์

เปิดลิงก์ไม่ได้

ตรวจว่าพีซีผู้ส่งเปิดอยู่ เชื่อมต่ออินเทอร์เน็ต ไม่อยู่ในโหมดสลีป และยังแชร์อยู่ ส่งลิงก์และรหัสผ่านปัจจุบันอีกครั้งและตรวจเครือข่ายผู้รับ หากเริ่มใหม่หรือเปลี่ยนเครือข่ายแล้วลิงก์เปลี่ยน ให้ส่งลิงก์ใหม่ การมีลิงก์ไม่ได้ยืนยันว่าผู้รับเชื่อมต่อได้ หากยังไม่ได้ให้ตรวจไฟร์วอลล์และเราเตอร์

ในสถานะการเชื่อมต่อ สีเทาหมายถึงรอหรือกำลังเตรียม และสีแดงหมายถึงข้อผิดพลาด สีน้ำเงินหมายถึง HTTPS พร้อมแต่ยังไม่ยืนยันการเข้าถึงภายนอก สีเขียวหมายถึงพบคำขอจากภายนอกที่ผ่านการยืนยันตัวตน การสร้างลิงก์เพียงอย่างเดียวไม่ยืนยันการเข้าถึงภายนอก

การเชื่อมต่อที่ปลอดภัย

แอปเตรียมการเชื่อมต่อ HTTPS ที่เข้ารหัส เครือข่ายหรือบริการใบรับรองอาจทำให้เตรียมไม่สำเร็จ หากเบราว์เซอร์เตือนด้านความปลอดภัย ให้ตรวจสอบลิงก์และวันที่เวลาของพีซี อย่าข้ามคำเตือนหรือปิดการป้องกัน

รหัสผ่านและการยืนยัน

แจ้งรหัสผ่านสี่หลักปัจจุบันแก่ผู้รับ หากผิดให้ตรวจตัวเลขและลิงก์ล่าสุด หากการยืนยันหมดอายุให้ตรวจว่ายังแชร์อยู่แล้วเข้าสู่ระบบอีกครั้ง หากเปลี่ยนรหัสผ่านให้หยุดแชร์ เปลี่ยนรหัส เริ่มใหม่ และส่งลิงก์กับรหัสปัจจุบัน

ปัญหาดาวน์โหลด

หากดาวน์โหลดหยุด ให้ตรวจพีซีผู้ส่ง การแชร์ พื้นที่ว่างและเครือข่ายผู้รับ แล้วลองใหม่ในเบราว์เซอร์ ZIP ของโฟลเดอร์ต้องมีพื้นที่ชั่วคราวบนพีซีผู้ส่งด้วย การดาวน์โหลดต่อขึ้นอยู่กับเบราว์เซอร์และเครือข่ายและไม่รับประกัน หากจำเป็นให้เริ่มดาวน์โหลดใหม่

ไฟร์วอลล์ Windows

Windows อาจขออนุมัติจากผู้ดูแลระหว่างเตรียมแชร์ เมื่ออนุมัติแอปจะพยายามเตรียมกฎไฟร์วอลล์ที่จำเป็น การปฏิเสธหรือนโยบายผู้ดูแลอาจจำกัดการเชื่อมต่อโดยตรง ตรวจเครือข่ายที่ใช้งานและแอปที่อนุญาตในความปลอดภัยของ Windows หากเป็นพีซีที่ทำงานหรือโรงเรียนให้ถามผู้ดูแล อย่าปิดไฟร์วอลล์ทั้งหมด

เราเตอร์และข้อจำกัดเครือข่าย

หากทำได้แอปจะเตรียมการเชื่อมต่อเราเตอร์โดยอัตโนมัติ เราเตอร์หลายตัวหรือการบล็อกขาเข้าจากผู้ให้บริการ ที่ทำงาน โรงเรียน หรือเครือข่ายสาธารณะอาจขัดขวางได้ แต่ชื่อเครือข่ายเพียงอย่างเดียวไม่ใช่หลักฐานว่าใช้ไม่ได้ ทำตามคำแนะนำกู้คืนเฉพาะเราเตอร์ที่คุณดูแล ตั้งค่าด้วยตนเองและอนุมัติการแชร์ครั้งนี้เมื่อระบบขอ ไม่รับประกันว่าจะสำเร็จ IPv6 ขึ้นอยู่กับเครือข่ายทั้งสองฝ่ายด้วย หากยังไม่ยืนยันให้ลองเครือข่ายอื่นหรือถามผู้ดูแล หากเส้นทางตรงที่รองรับทั้งหมดถูกบล็อกและเปลี่ยนไม่ได้ ผลิตภัณฑ์นี้แก้ไขไม่ได้ และเราไม่แนะนำให้ซื้อหรือใช้ในสภาพแวดล้อมนั้น

หากหน้ากู้คืน IPv4 แบบกำหนดเองปรากฏ ให้ส่งต่อพอร์ตไฟล์ที่แสดงบนเราเตอร์ที่คุณดูแล ตั้งกฎ TCP 80 สำหรับใบรับรองเฉพาะเมื่อหน้าจอระบุให้ทำ ยืนยันหลังตั้งค่าที่จำเป็นเสร็จ ต้องตรวจการเข้าถึงจากภายนอกแยกต่างหาก

รักษาการแชร์และตั้งค่า

เปิดพีซีผู้ส่งและอินเทอร์เน็ตไว้ ขณะปิดหน้าต่างสามารถเลือกให้ทำงานต่อในถาดระบบ จากถาดสามารถเปิดหน้าต่าง คัดลอกลิงก์ หยุดหรือออกได้ หยุดหรือออกเพื่อจบอย่างปลอดภัย เปลี่ยนภาษาและรูปแบบได้ในแอป

Microsoft Store

เวอร์ชัน Microsoft Store อาจต้องตรวจสอบสิทธิ์ใช้งานที่ถูกต้องก่อนแชร์ครั้งใหม่ หากกำลังตรวจหรือไม่สำเร็จ ให้ตรวจบัญชีที่ใช้รับแอปแล้วลองใหม่ภายหลัง ดูเงื่อนไขทดลองหรือคืนเงินที่ Microsoft Store แสดงตอนซื้อ

ความช่วยเหลือเพิ่มเติม

จดสถานะการแชร์ เวลาที่เกิดข้อผิดพลาด และเวอร์ชัน Windows กับแอป ใช้การคัดลอกบันทึกเพื่อเตรียมข้อมูลวินิจฉัย บันทึกอาจมีข้อมูลพีซีหรือเครือข่าย จึงควรลบรหัสผ่าน PIN ลิงก์แชร์ โทเคน และคีย์ส่วนตัวก่อนส่ง
