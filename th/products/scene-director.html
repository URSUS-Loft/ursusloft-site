Scene Director

การกำกับงานสร้างสรรค์แบบมีโครงสร้างสำหรับการสร้างภาพ image-to-image

เครื่องมือบนเครื่องสำหรับร่างพรอมต์และจัดระเบียบภาพอ้างอิงเพื่อใช้กับบริการสร้างภาพ AI ภายนอก

พื้นที่ทำงานที่มุ่งเน้นการกำกับ image-to-image

จัดระเบียบบทบาทของภาพอ้างอิง ตัวควบคุมฉาก และพรอมต์สุดท้ายไว้ในขั้นตอนการทำงานบนเครื่องเดียวกัน

เครื่องมือบนเครื่องสำหรับกำกับพรอมต์

Scene Director ไม่ใช่ AI สร้างภาพหรือเซิร์ฟเวอร์สร้างภาพ และไม่อัปโหลดภาพอ้างอิงไปยังบริการอื่นโดยอัตโนมัติ แอปช่วยจัดบทบาทของภาพและทิศทางสร้างสรรค์ แล้วประกอบเป็น Final Prompt ภาษาอังกฤษ ผู้ใช้คัดลอกพรอมต์ไปยังบริการภายนอกและอัปโหลดภาพอ้างอิงด้วยตนเอง

สร้าง คัดลอก และใช้พรอมต์

เลือกภาพอ้างอิง

เลือก Project Type เพิ่มภาพอ้างอิงได้สูงสุดห้าภาพ และกำหนดบทบาทที่ชัดเจนให้แต่ละภาพ

กำกับฉาก

ตั้งค่าตัวละคร กล้อง ท่าทาง ใบหน้า เครื่องแต่งกาย สภาพแวดล้อม การเรนเดอร์ และคำสั่งเพิ่มเติม

คัดลอกพรอมต์สุดท้าย

คัดลอก Final Prompt ภาษาอังกฤษ แล้วอัปโหลดภาพอ้างอิงชุดเดิมไปยังเครื่องมือภายนอกตามลำดับเดียวกัน

ตัวควบคุมปัจจุบัน

บทบาทของภาพอ้างอิง

กำหนดบทบาทให้แต่ละภาพ ช่องว่างและภาพที่ยังเป็น Role Required จะไม่รวมในผลลัพธ์พรอมต์

Creative Direction

ตั้งค่า Character, Camera, Pose, Face, Costume, Environment, Rendering และ Additional Instructions

Final Prompt และ Compact Prompt

สร้างพรอมต์ภาษาอังกฤษแบบละเอียดหรือแบบกระชับจากการตั้งค่าปัจจุบัน

เซสชันและพรีเซ็ตบนเครื่อง

กู้คืนเซสชันล่าสุดโดยอัตโนมัติ และบันทึก โหลด หรือลบพรีเซ็ตที่ตั้งชื่อไว้บนเครื่อง

รักษาลำดับภาพอ้างอิงให้ตรงกัน

แนบภาพชุดเดิมไปยังเครื่องมือ AI ภายนอกตามลำดับที่ Scene Director แสดง

การให้บริการ

  • Windows
  • พร้อมใช้งานแล้ว

เหมาะสำหรับใคร

เหมาะสำหรับผู้สร้างภาพ AI ศิลปินสตอรีบอร์ดและคอนเซปต์ นักออกแบบ ผู้กำกับภาพ ผู้ทำงานกับตัวละครซ้ำ และผู้ที่ต้องสร้างพรอมต์ image-to-image ที่ซับซ้อนเป็นประจำ

คำถามที่พบบ่อย

Scene Director สร้างภาพหรือไม่

ไม่ แอปเตรียมพรอมต์และข้อมูลจัดระเบียบภาพอ้างอิงสำหรับบริการสร้างภาพภายนอก

แอปอัปโหลดภาพอ้างอิงหรือไม่

ไม่ ภาพถูกเลือกไว้บนเครื่อง คุณต้องอัปโหลดไปยังบริการภายนอกด้วยตนเอง

เหตุใดลำดับภาพจึงสำคัญ

เมื่อพรอมต์อ้างถึงลำดับภาพ การใช้ภาพชุดเดิมตามลำดับเดิมทำให้ทำตามขั้นตอนได้ง่ายขึ้น

Final Prompt ต่างจาก Compact Prompt อย่างไร

Final Prompt เป็นผลลัพธ์ภาษาอังกฤษแบบละเอียด ส่วน Compact Prompt เป็นเวอร์ชันที่สั้นกว่า

เซสชันและพรีเซ็ตเก็บที่ใด

จัดเก็บบนเครื่องที่ %APPDATA%\Scene Director

รับประกันความสม่ำเสมอของตัวละครหรือไม่

ไม่ บทบาทที่ชัดเจนช่วยลดความขัดแย้ง แต่บริการภายนอกและผลลัพธ์อยู่นอกการควบคุมของแอป
