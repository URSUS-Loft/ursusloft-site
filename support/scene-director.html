Scene Director

Support

Guidance for the current Scene Director workflow on Windows.

Getting started

Scene Director is a local prompt drafting and scene direction utility for external AI image generation tools. It organizes reference-image roles, scene directions, and Final Prompt or Compact Prompt output in English.

  1. Select a Project Type.
  2. Add up to five Reference Images and assign a clear role to each image you want to use.
  3. Set Character, Camera, Pose, Face, Costume, Environment, Rendering, and Additional Instructions.
  4. Review the Final Prompt or Compact Prompt.
  5. Copy the prompt into an external AI image generation tool and attach the same reference images in the same order.

Reference Images and roles

Reference Images are not uploaded or analyzed by Scene Director. They are selected from your local device for local preview and prompt organization.

Attach the same reference images to the external AI tool in the exact order shown in Scene Director. A changed order can cause the external tool to follow the wrong source. Empty slots and images whose role remains Role Required are excluded from Final Prompt and Compact Prompt.

Prompt controls

The sidebar provides Project Type, Character, Multi-Character, Camera, Pose, Face, Costume, Environment, Rendering, and Additional Instructions controls. The Help dialog also includes Reference Images, Final Prompt (English), and Composition Preview.

Final Prompt is the detailed English prompt generated from the current settings. It remains English-only by design and is more detailed than Compact Prompt. Scene Director does not generate the final image directly.

Sessions and presets

Scene Director automatically saves the current session and restores it when the app opens. The status bar shows Auto saved and Last saved: just now.

Use Save Preset to store the current state by name. Load Preset restores a saved preset and Delete Preset removes one. Saving a preset with an existing name updates that preset.

Use New Prompt to reset the current prompt workspace to its defaults. Saved presets are not deleted.

Last-session data is stored in %APPDATA%\Scene Director\last_session.json. Presets are stored in %APPDATA%\Scene Director\presets.json.

Platform and external services

Scene Director is currently for Windows. It is not an image generation service and does not upload reference images to another service for you. You choose the external AI image generation service and upload reference images there yourself.
