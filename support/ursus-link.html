URSUS Link

Support

Help for sharing files directly from your Windows PC.

Getting started

URSUS Link shares files from a folder on your PC directly to a recipient's browser. Files are not uploaded to URSUS Loft cloud storage.

  1. Choose Shared Folder.
  2. Review or change the four-digit Password.
  3. Select Start Sharing.
  4. Wait for the Share Link to be created.
  5. Send the Share Link and password to the recipient.
  6. The recipient opens the link, enters the PIN/password, and downloads the files.
  7. Select Stop Sharing when you are finished.

Share link and browser downloads

The recipient does not need URSUS Link installed. A current web browser is enough. Keep the Share Link and password private, and keep the sender PC online while sharing.

HTTPS and HTTP fallback

URSUS Link normally prepares HTTPS and makes up to three eligible setup attempts. If HTTPS still cannot be prepared, you may explicitly choose HTTP fallback. That sharing session is not encrypted in transit.

Large files and background sharing

Large files stream from disk and support Range/resume requests. Folder downloads may use a temporary local ZIP64 package. URSUS Link can remain available from the system tray while sharing; keep the app and PC running until transfers finish.

Connection troubleshooting

If the link cannot be opened, confirm that sharing is active, copy the current link again, keep the sender PC online, and allow Windows Firewall access when prompted. Some routers, CGNAT, corporate, public, or mobile networks can block direct incoming connections.
