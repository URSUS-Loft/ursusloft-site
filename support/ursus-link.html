Help for sharing files directly from your Windows PC.

Share files and folders directly from your PC. Send the link and password privately, only to people you trust.

Start sharing

Choose Change next to the shared folder and select the folder containing your files. Check the four-digit password and select Start Sharing. When the link appears, copy it and send it with the password to the recipient. They open the link in a browser, enter the password, and download the files or folders they need. Select Stop Sharing when finished.

If the link will not open

Check that the sending PC is on, awake, connected to the internet, and still sharing. Send the current link and password again and check the recipient’s connection. If a restart or network change produced a new link, send that link. A displayed link does not prove that the recipient can connect. If it still fails, check the firewall and router guidance below.

In Connection Status, grey means waiting or preparing and red means an error. Blue means HTTPS sharing is ready but external access is unverified. Green means an authenticated external request was observed. A generated link alone does not prove external access.

Secure connection

The app prepares an encrypted HTTPS connection. Preparation can fail because of the network or certificate service. If the browser shows a security warning, check the link and the PC date and time. Do not bypass the warning or disable protection.

Password and authentication

Give the recipient the current four-digit password. If it fails, check the digits and the current link. If browser authentication expires, check that sharing is still active and authenticate again with the current password. To change the password, stop sharing, change it, start again, and send the current link and password.

Download problems

If a download stops, check that the sending PC and share are still on, and that the recipient has enough storage and an internet connection. Retry in the browser. Folder ZIP downloads also need free space for temporary files on the sending PC. Resuming depends on the browser and connection and is not guaranteed; download again from the beginning if necessary.

Windows Firewall

Windows may ask for administrator approval while preparing a share. Approval lets the app attempt to prepare the necessary firewall rules. Refusal or an administrator policy can restrict direct connections. Check the active network and allowed apps in Windows Security’s firewall settings; on a work or school PC, ask your administrator. Do not turn off the whole firewall.

Routers and network limits

When possible the app prepares the router connection automatically. Multiple routers or an internet provider, workplace, school or public network that blocks incoming connections can prevent sharing, but the network name alone does not prove it cannot work. If recovery instructions appear, check settings only on routers you control; follow the screen when manual settings and approval for this share are required. Changes do not guarantee access. An available IPv6 path also depends on both networks. If access is unverified, try another network or ask the administrator. If all supported direct paths are blocked and cannot be changed, this product cannot solve that environment; we do not recommend purchasing or using it there.

If manual IPv4 recovery appears, forward the file port shown on screen on a router you control. Set up the certificate TCP 80 rule only if the screen requires it. Confirm after completing the required settings. Check external access separately.

Keep sharing and settings

Keep the sending PC and internet connection on while sharing. When closing the window you can choose to keep the app in the system tray. From the tray you can open the window, copy the link, stop sharing or exit. Stop sharing or exit to end access safely. Change language and appearance from the app screen.

Microsoft Store

The Microsoft Store version may need to verify a valid license before a new share starts. If verification is pending or fails, check that the Store is signed in to the account used to acquire the app, then select Start Sharing again later. Check Microsoft Store’s terms shown at purchase for trial or refund conditions.

More help

Note the share status, when the error occurred, and the Windows and app versions. Copy Log can prepare a diagnostic record. It may contain PC or network information; remove passwords, PINs, share links, tokens and private keys before sharing it.
