URSUS Link

गोपनीयता नीति

प्रभावी तिथि: 24 अगस्त 2026

1. परिचय

URSUS Link का संचालन URSUS Loft करता है। यह भेजने वाले को अपने PC से प्राप्तकर्ता के वेब ब्राउज़र तक फ़ाइलें सीधे साझा करने देता है।

2. संसाधित जानकारी

साझाकरण के लिए ऐप चुना हुआ फ़ोल्डर; फ़ाइल नाम, पथ, metadata और सामग्री; Share Link token; PIN और प्राप्तकर्ता session data; स्थानीय network व connection जानकारी; तथा request और transfer जानकारी संसाधित करता है। Copy Link चुनने पर लिंक Windows clipboard में लिखा जाता है, लेकिन clipboard की सामग्री पढ़ी नहीं जाती।

कोई user account system नहीं है और payment-card जानकारी सीधे संसाधित नहीं होती। विज्ञापन analytics, व्यवहार tracking या third-party advertising SDK नहीं हैं।

3. साझा की गई फ़ाइलें

ऐप भेजने वाले द्वारा चुनी फ़ाइलों और फ़ोल्डरों तक पहुँचता है। वे भेजने वाले के PC से प्राप्तकर्ता के browser को सीधे भेजे जाते हैं; URSUS Loft cloud storage या relay पर upload नहीं होते।

फ़ोल्डर या कई items के लिए भेजने वाले के PC पर स्थानीय ZIP64 package बनाया और सीधे परोसा जा सकता है।

4. Network और connection जानकारी

सीधे sharing की तैयारी और diagnosis के लिए local IP, default gateway, Windows network/firewall state, public IP और port संसाधित हो सकते हैं। PIN प्रयास सीमित करने और transfer संभालने के लिए recipient IP तथा आवश्यक request, Range, session और file जानकारी अस्थायी रूप से संसाधित हो सकती है।

Recipient IP, PIN, Share Link token और session cookie diagnostic logs में नहीं रखे जाते।

5. स्थानीय data storage

%LOCALAPPDATA%\URSUS Link में settings, rotating logs, स्थानीय रूप से बने TLS/ACME keys और certificates, तथा ZIP cache रखे जा सकते हैं। Settings में अंतिम folder, भाषा और sharing के दौरान close preference शामिल हैं।

Logs स्थानीय रहते हैं और अपने-आप URSUS Loft को upload नहीं होते। पूरे Windows paths, raw IP, PIN, token, cookie और secret-जैसे values छिपाए जाते हैं।

6. Third-party services

Public IP जानने के लिए api.ipify.org, icanhazip.com या ifconfig.me उपयोग हो सकते हैं। इन्हें connection IP और User-Agent मिलता है और वे public IPv4 लौटाते हैं; files, PIN और Share Link token नहीं भेजे जाते।

HTTPS certificate के लिए Let's Encrypt उपयोग हो सकता है। आवश्यक request और validation data भेजे जाते हैं; TLS और ACME account private keys sender PC पर रहते हैं। App सीधे external connection के लिए local router से भी संवाद कर सकता है।

7. Connection security

URSUS Link सामान्यतः HTTPS link तैयार करता है और योग्य failures पर तीन बार तक retry करता है। HTTPS न बन सके तो sender स्पष्ट रूप से HTTP जारी रखना, HTTPS फिर प्रयास करना या cancel चुन सकता है। HTTP कभी अपने-आप नहीं चुना जाता।

HTTP में उस sharing session का data transit में encrypted नहीं होता।

8. Data retention

Active session और transfer data memory में रहता है। Authentication sessions आठ घंटे बाद समाप्त होते हैं और sharing रुकने पर active state साफ होता है। Completed packages 24 घंटे बाद और cache-size cleanup में हट सकते हैं। Logs size के आधार पर rotate होते हैं।

Uninstall के बाद कुछ settings, logs, TLS material और cache रह सकते हैं। %LOCALAPPDATA%\URSUS Link manually हटाया जा सकता है।

9. Data sharing

Files, names, listings और folder/package contents Share Link उपयोग करने और PIN पूरा करने वाले recipient को सीधे दिए जाते हैं। IP और certificate services को केवल आवश्यक जानकारी मिलती है। URSUS Loft URSUS Link transfers के लिए cloud relay या storage नहीं चलाता।

10. आपके विकल्प

आप folder चुन सकते हैं, PIN बदल या पुनः बना सकते हैं, sharing रोक सकते हैं और uninstall के बाद local data हटा सकते हैं। Sharing रोकने पर local server बंद और active Share Link अनुपलब्ध हो जाता है।

11. बच्चों की गोपनीयता

URSUS Link file-sharing tool है और इसमें बच्चों के account या profile नहीं हैं।

12. नीति में बदलाव

Data practices बदलने पर URSUS Loft नीति update कर सकता है। संशोधित नीति प्रकाशित होने पर प्रभावी तिथि update होगी।

13. संपर्क

प्रश्न support@ursusloft.com पर भेजें।
