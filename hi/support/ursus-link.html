URSUS Link

सहायता

Windows PC से सीधे फ़ाइलें साझा करने में सहायता।

शुरू करना

URSUS Link आपके PC पर चुने गए फ़ोल्डर की फ़ाइलें सीधे प्राप्तकर्ता के ब्राउज़र से साझा करता है। फ़ाइलें URSUS Loft cloud storage पर अपलोड नहीं होतीं।

  1. Shared Folder चुनें।
  2. चार अंकों का Password जाँचें या बदलें।
  3. Start Sharing चुनें।
  4. Share Link बनने की प्रतीक्षा करें।
  5. Share Link और पासवर्ड प्राप्तकर्ता को भेजें।
  6. प्राप्तकर्ता लिंक खोलता है, PIN/पासवर्ड डालता है और फ़ाइलें डाउनलोड करता है।
  7. पूरा होने पर Stop Sharing चुनें।

शेयर लिंक और ब्राउज़र डाउनलोड

प्राप्तकर्ता को URSUS Link इंस्टॉल करने की आवश्यकता नहीं है; आधुनिक वेब ब्राउज़र पर्याप्त है। Share Link और पासवर्ड निजी रूप से भेजें और साझा करते समय भेजने वाले PC को ऑनलाइन रखें।

HTTPS और HTTP fallback

URSUS Link सामान्यतः HTTPS तैयार करता है और योग्य setup failure पर अधिकतम तीन बार फिर कोशिश करता है। HTTPS फिर भी तैयार न हो तो आप स्पष्ट रूप से HTTP fallback चुन सकते हैं। उस sharing session का data transit में encrypted नहीं होगा।

बड़ी फ़ाइलें और background sharing

बड़ी फ़ाइलें disk से stream होती हैं और Range/resume request का समर्थन करती हैं। Folder download अस्थायी local ZIP64 package का उपयोग कर सकता है। साझा करते समय URSUS Link system tray में चलता रह सकता है; transfer पूरा होने तक app और PC चालू रखें।

कनेक्शन की समस्या हल करना

यदि लिंक नहीं खुलता, तो sharing सक्रिय होने की पुष्टि करें, वर्तमान लिंक फिर copy करें और भेजने वाले PC को online रखें। पूछे जाने पर Windows Firewall access की अनुमति दें। कुछ router, CGNAT, corporate, public या mobile network सीधे incoming connection को रोक सकते हैं।
