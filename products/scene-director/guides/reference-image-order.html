Guide

Why reference image order matters

Keep role assignments and image sequence visible when you move from prompt preparation to an external generation workflow.

On this page

  1. Define roles
  2. Keep the same sequence
  3. Review before generation

Reference images need defined roles

Reference images can communicate face, body, costume, environment, pose, or rendering direction. Assigning a role makes it clear which image supports each instruction.

Keep the same images in the same sequence

When a prompt refers to image order, upload the same selected images in that order to the external service. This is a workflow principle, not a claim that every service interprets images in exactly the same way.

Empty slots and excluded images

Do not invent a role for an empty slot. In Scene Director, empty slots and Role Required images are excluded from prompt output. Check what is included before copying a prompt.

Common ordering mistakes

Changing order after writing the prompt, replacing an image without reviewing its role, and using conflicting identity sources make a workflow harder to check.

Pre-generation checklist

  • Confirm each selected image has a purpose.
  • Check prompt reference order.
  • Upload the same images in the same sequence.
  • Remove unused or excluded sources.

How Scene Director keeps order visible

Scene Director shows up to five reference slots and assigned roles while you build a Final Prompt or Compact Prompt. The app does not upload images; you attach them in the external workflow.
